# Mac：一键恢复临时访问入口

双击桌面的 **`知行-恢复访问入口.command`**。也可以在仓库的 `scripts/` 文件夹里双击 **`恢复访问入口.command`**。

脚本会：

1. 启动 Docker Desktop（若未运行），等待 Compose 服务健康；不重建镜像、不清空数据库。
2. 检查已有的师生档案预览和访问网关的 macOS 登录自启任务。
3. 重启 Docker 主站与档案预览的 Cloudflare 临时隧道，等待连接并从外网验证页面。
4. 在终端展示最新地址，并更新桌面的 **`知行最新访问地址.txt`**。地址文件只含 URL，不含账号或口令。

**每次点击可能生成不同的 `trycloudflare.com` 地址**，以前的书签通常会失效。电脑休眠或关机后再打开，重新双击脚本，复制新地址即可。终端窗口会停留至按回车，便于复制链接。

Docker 隧道由 `~/Library/LaunchAgents/com.zhinengqa.docker-quick-tunnel.plist` 管理；原有预览及访问网关任务不改动。仅在当前用户登录后才会运行。如果脚本提示“外网访问未能核实”，不要将旧地址当作有效地址，检查网络、Docker 和 cloudflared 后再运行一次。

若以后需要**永不变化的网址**，需要自有域名和 Cloudflare 命名隧道（Quick Tunnel 无法固定域名）。
