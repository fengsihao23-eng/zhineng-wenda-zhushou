## 1. 数据隔离原则

所有学校业务表必须有明确的数据隔离字段。

### 1.1 必需字段

**核心隔离**：
```sql
school_id UUID NOT NULL
```

**可选扩展**：
```sql
campus_id UUID           -- 多校区
academic_year_id UUID    -- 学年
term_id UUID            -- 学期
```

### 1.2 查询原则

所有多学校查询索引应考虑 `school_id` 前缀。

## 2. 核心身份表

### 2.1 schools - 学校表

```sql
CREATE TABLE schools (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(200) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_schools_code ON schools(code);
CREATE INDEX idx_schools_status ON schools(status);
```

### 2.2 users - 用户表

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    username VARCHAR(100) NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    display_name VARCHAR(100),
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    last_login_at TIMESTAMP,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    
    UNIQUE(school_id, username)
);

CREATE INDEX idx_users_school ON users(school_id);
CREATE INDEX idx_users_username ON users(school_id, username);
CREATE INDEX idx_users_status ON users(status);
```

### 2.3 roles - 角色表

```sql
CREATE TABLE roles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    description TEXT
);

    ('TEACHER', '教师'),
```

### 2.4 user_roles - 用户角色关联

```sql
CREATE TABLE user_roles (
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    role_id UUID NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    school_id UUID NOT NULL REFERENCES schools(id),
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    
    PRIMARY KEY (user_id, role_id)
);

CREATE INDEX idx_user_roles_user ON user_roles(user_id);
CREATE INDEX idx_user_roles_school ON user_roles(school_id);
```

### 2.5 students - 学生表

```sql
CREATE TABLE students (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    user_id UUID REFERENCES users(id),
    external_student_id VARCHAR(100),        -- 外部系统学生ID
    student_no VARCHAR(50),                   -- 学号
    name VARCHAR(100) NOT NULL,
    grade_id UUID,                            -- 年级
    class_id UUID,                            -- 班级
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    source_system VARCHAR(50),                -- 数据来源系统
    source_updated_at TIMESTAMP,              -- 源系统更新时间
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    
    UNIQUE(school_id, external_student_id),
    UNIQUE(school_id, student_no)
);

CREATE INDEX idx_students_school ON students(school_id);
CREATE INDEX idx_students_user ON students(user_id);
CREATE INDEX idx_students_grade_class ON students(grade_id, class_id);
CREATE INDEX idx_students_external ON students(school_id, external_student_id);
```

**重要原则**：
> **模型 Tool 永远不能接受任意 `student_id` 来读取数据。**

学生身份来自：
```text
JWT → current_user → bound_student_id
```

## 3. 考试成绩数据模型

### 3.1 exams - 考试表

```sql
CREATE TABLE exams (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    external_exam_id VARCHAR(100),
    name VARCHAR(200) NOT NULL,
    exam_type VARCHAR(50) NOT NULL,           -- 'midterm', 'final', 'monthly'
    academic_year VARCHAR(20),
    term VARCHAR(20),                         -- 'spring', 'fall'
    grade_id UUID,
    start_date DATE,
    end_date DATE,
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    source_system VARCHAR(50),
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    
    UNIQUE(school_id, external_exam_id)
);

CREATE INDEX idx_exams_school ON exams(school_id);
CREATE INDEX idx_exams_school_date ON exams(school_id, start_date DESC);
CREATE INDEX idx_exams_grade ON exams(grade_id);
```

### 3.2 subjects - 科目表

```sql
CREATE TABLE subjects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    code VARCHAR(50) NOT NULL,
    name VARCHAR(100) NOT NULL,
    
    UNIQUE(school_id, code)
);

CREATE INDEX idx_subjects_school ON subjects(school_id);

INSERT INTO subjects (school_id, code, name) VALUES
    ('school_uuid', 'MATH', '数学'),
    ('school_uuid', 'CHINESE', '语文'),
    ('school_uuid', 'ENGLISH', '英语'),
    ('school_uuid', 'PHYSICS', '物理'),
    ('school_uuid', 'CHEMISTRY', '化学');
```

### 3.3 exam_subjects - 考试科目

```sql
CREATE TABLE exam_subjects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    exam_id UUID NOT NULL REFERENCES exams(id) ON DELETE CASCADE,
    subject_id UUID NOT NULL REFERENCES subjects(id),
    full_score DECIMAL(10,2) NOT NULL,

);

CREATE INDEX idx_exam_subjects_exam ON exam_subjects(exam_id);
```

### 3.4 student_exam_scores - 学生考试总分

```sql
CREATE TABLE student_exam_scores (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    student_id UUID NOT NULL REFERENCES students(id),
    exam_id UUID NOT NULL REFERENCES exams(id),
    total_score DECIMAL(10,2) NOT NULL,
    class_rank INT,
    grade_rank INT,
    class_student_count INT,

    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    
    UNIQUE(student_id, exam_id)

CREATE INDEX idx_student_exam_scores_student ON student_exam_scores(student_id, exam_id);
CREATE INDEX idx_student_exam_scores_exam ON student_exam_scores(exam_id);
```

### 3.5 student_subject_scores - 学生科目成绩

```sql
CREATE TABLE student_subject_scores (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    student_id UUID NOT NULL REFERENCES students(id),
    exam_id UUID NOT NULL REFERENCES exams(id),
    subject_id UUID NOT NULL REFERENCES subjects(id),
    score DECIMAL(10,2) NOT NULL,
    full_score DECIMAL(10,2) NOT NULL,
    class_rank INT,
    grade_rank INT,
    class_avg DECIMAL(10,2),
    grade_avg DECIMAL(10,2),
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    
    UNIQUE(student_id, exam_id, subject_id)
);

CREATE INDEX idx_student_subject_scores_student ON student_subject_scores(student_id, exam_id);
CREATE INDEX idx_student_subject_scores_subject ON student_subject_scores(student_id, subject_id);
```

### 3.6 question_scores - 小题得分

```sql
CREATE TABLE question_scores (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    student_id UUID NOT NULL REFERENCES students(id),
    exam_id UUID NOT NULL REFERENCES exams(id),
    subject_id UUID NOT NULL REFERENCES subjects(id),
    question_id UUID,                         -- 关联题库（可选）
    question_no VARCHAR(20) NOT NULL,         -- 题号
    score DECIMAL(10,2) NOT NULL,
    full_score DECIMAL(10,2) NOT NULL,
    lost_score DECIMAL(10,2) NOT NULL,        -- 由代码计算
    answer_status VARCHAR(20),                -- 'correct', 'partial', 'wrong'
    knowledge_point_id UUID,                  -- 关联知识点（可选）
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    
    UNIQUE(student_id, exam_id, subject_id, question_no)
);

CREATE INDEX idx_question_scores_student_exam ON question_scores(student_id, exam_id);
CREATE INDEX idx_question_scores_subject ON question_scores(student_id, exam_id, subject_id);
CREATE INDEX idx_question_scores_lost ON question_scores(student_id, exam_id, lost_score DESC);
```

**确定性字段必须由代码算**：
```python
lost_score = full_score - score
score_rate = score / full_score
rank_delta = previous_rank - current_rank
score_delta = current_score - previous_score
```

**禁止让 LLM 自己心算这些数据。**

## 4. 学情诊断模型

### 4.1 diagnosis_reports - 诊断报告

```sql
CREATE TABLE diagnosis_reports (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    student_id UUID NOT NULL REFERENCES students(id),
    exam_id UUID REFERENCES exams(id),
    subject_id UUID REFERENCES subjects(id),
    report_type VARCHAR(50) NOT NULL,         -- 'exam', 'subject', 'semester'
    status VARCHAR(20) NOT NULL DEFAULT 'generated',
    source_system VARCHAR(50),
    raw_content TEXT,                         -- 原始报告
    structured_json JSONB NOT NULL,           -- 结构化JSON
    version VARCHAR(20),
    generated_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_diagnosis_reports_student ON diagnosis_reports(student_id, exam_id);
CREATE INDEX idx_diagnosis_reports_exam ON diagnosis_reports(exam_id);
CREATE INDEX idx_diagnosis_reports_subject ON diagnosis_reports(student_id, subject_id);
CREATE INDEX idx_diagnosis_reports_json ON diagnosis_reports USING GIN(structured_json);
```

## 5. Chat 数据模型

### 5.1 chat_sessions - 对话会话

```sql
CREATE TABLE chat_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    school_id UUID NOT NULL REFERENCES schools(id),
    student_id UUID NOT NULL REFERENCES students(id),
    title VARCHAR(200),
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    selected_exam_id UUID REFERENCES exams(id),  -- 当前选中考试
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    last_message_at TIMESTAMP
);

CREATE INDEX idx_chat_sessions_student ON chat_sessions(student_id, last_message_at DESC);
CREATE INDEX idx_chat_sessions_exam ON chat_sessions(selected_exam_id);
```

### 5.2 chat_messages - 对话消息

```sql
CREATE TABLE chat_messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id UUID NOT NULL REFERENCES chat_sessions(id) ON DELETE CASCADE,
    role VARCHAR(20) NOT NULL,                -- 'user', 'assistant', 'system'
    content TEXT NOT NULL,
    model_id VARCHAR(100),
    agent_run_id UUID,
    token_input INT,
    token_output INT,
    created_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_chat_messages_session ON chat_messages(session_id, created_at);
CREATE INDEX idx_chat_messages_agent_run ON chat_messages(agent_run_id);
```

**不要在 chat_messages 里塞完整 Tool raw response。**

## 8. 数据完整性约束

### 8.1 级联删除策略

- **学生删除**：软删除（status='deleted'），保留历史数据
- **考试删除**：不允许删除有成绩的考试
- **会话删除**：级联删除所有消息

### 8.2 必需字段校验

```python
# Pydantic 模型示例
class StudentExamScore(BaseModel):
    school_id: UUID
    student_id: UUID
    exam_id: UUID
    total_score: Decimal
    
    @validator('total_score')
    def score_must_be_positive(cls, v):
        if v < 0:
            raise ValueError('分数不能为负')
        return v
```

## 9. 数据迁移策略

### 9.1 外部系统映射

所有从旧系统或外部系统同步的数据：

```sql
external_id VARCHAR(100)      -- 外部系统ID
source_system VARCHAR(50)     -- 来源系统标识
source_updated_at TIMESTAMP   -- 源更新时间
source_hash VARCHAR(64)       -- 数据指纹（检测变化）
```

### 9.2 唯一约束

```sql
UNIQUE(school_id, source_system, external_id)
```

确保同步幂等性。

## 10. 关键要点

1. **所有业务表必须有 school_id**
2. **学生身份来自 JWT，不允许模型指定 student_id**
3. **确定性计算字段由代码完成，不依赖 LLM**
4. **诊断报告使用 JSONB 存储结构化内容**
5. **外部系统数据必须有 external_id 和 source_system**
6. **所有 DB 变更必须通过 Alembic Migration**
7. **索引优化关注学生视角的高频查询**
