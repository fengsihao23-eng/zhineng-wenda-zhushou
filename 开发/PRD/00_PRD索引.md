## 🎯 关键决策点

### V2 试点目标（不是完成声明）

- 学生真实成绩事实问答（必须先通过垂直闭环验收）
- BASIC 权限边界；DIAGNOSIS 后置到独立版本
- 轻量 Agent + Tool Calling
- PostgreSQL + FastAPI
- CSV/Excel 为主、Adapter 为补充的数据接入

### 一期明确不做的

❌ 复杂 Multi-Agent 编排  
❌ 让模型直接查 SQL  
❌ 依赖 RAG 回答成绩问题  
❌ 让 LLM 计算确定性数值  
❌ BASIC 用户推断诊断结论
