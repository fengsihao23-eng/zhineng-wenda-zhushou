## 1. 核心概念

这是一期最重要的产品规则之一。

### 1.1 两层权益

| 权益层级 | 产品码 | 说明 |
|---|---|---|
| BASIC | 免费 | 只能查看客观数据 |
| DIAGNOSIS | 付费 | 额外可读诊断报告 |

---

## 2. BASIC 权益

### 2.1 允许读取

✅ **客观数据**：
- 学生自己的身份
- 考试列表
- 总分
- 单科成绩
- 班级排名
- 年级排名
- 历史趋势
- 小题得分
- 客观计算的差值、得分率、排名变化

### 2.2 不允许

❌ **诊断性内容**：
- 读取付费诊断报告
- 自行推断薄弱知识点
- 自行推断失分原因
- 伪造学习建议所依据的诊断结论
- 对学生能力做主观判断

### 2.3 示例对话

**用户问**：我这次数学考得怎么样？

**BASIC 正确回答**：
```text
你这次数学考了 86 分（满分 100），
班级排名第 31 名，年级排名第 128 名。
比上次月考少了 5 分，排名下降了 9 名。
```

**用户问**：我为什么数学退步了？

**BASIC 正确回答**：
```text
从现有成绩数据能确定的是：
这次数学比上次少 5 分，主要丢分集中在第 17、20、22 题。

目前没有可读取的学情诊断报告，
所以我不能直接判断具体原因。
```

**BASIC 错误回答**（禁止）：
```text
❌ 说明你函数概念不扎实，基础不牢。
❌ 可能是粗心导致的。
❌ 你需要加强代数部分的练习。
```

---

## 3. DIAGNOSIS 权益

### 3.1 在 BASIC 基础上额外允许

✅ **诊断报告访问**：
- 读取已购买的对应诊断报告
- 回答报告中的薄弱点
- 回答报告中的优势
- 回答报告中的失分原因
- 回答报告中的建议
- 回答报告中的诊断依据

### 3.2 关键限制

⚠️ **重要原则**：
> 模型只能整理、解释已有诊断，不能把"模型自己的猜测"包装成诊断报告结论。

### 3.3 示例对话

**用户问**：我为什么数学退步了？

**DIAGNOSIS 正确回答**（已购买报告）：
```text
你的诊断报告把主要原因指向函数综合题的步骤转换不稳定。

结合本次小题数据，第 20、22 题丢分也比较集中，
这两题都是函数应用题。

报告建议：
1. 加强函数定义域和值域的转换练习
2. 重点复习分段函数的解题步骤
```

**DIAGNOSIS 错误回答**（禁止）：
```text
❌ 虽然报告没写，但我觉得你还需要...
❌ 除了报告说的，你可能还有...的问题
❌ 报告可能遗漏了...
```

## 4. 权限校验架构

### 4.1 错误实现（禁止）

```python
SYSTEM_PROMPT = """
如果学生没买报告，请不要调用诊断工具。
"""
```

❌ **这不够！模型可能被 Prompt Injection 绕过。**

### 4.2 正确实现

```text
Agent
  ↓
ToolRegistry
  ↓
DiagnosisTool
  ↓
EntitlementService.assert_allowed(...)  # 👈 关键
  ↓
DiagnosisRepository
```

**即使模型试图越权**：
```python
get_diagnosis_report(student_id="别人的ID")
```
也必须被服务层拒绝。

### 4.3 权限检查点

```python
class DiagnosisTool:
    async def execute(self, tool_context: ToolContext, args: dict) -> ToolResult:
        # 1. 验证当前学生权益
        entitlement = await self.entitlement_service.check(
            student_id=tool_context.student_id,
            product_code="DIAGNOSIS_REPORT",
            resource_id=args.get("exam_id")
        )
        
        if not entitlement.is_active:
            return ToolResult(
                ok=False,
                error_code="ENTITLEMENT_REQUIRED",
                data={"message": "此功能需要购买学情诊断报告"}
            )
        
        # 2. 验证资源归属
        report = await self.diagnosis_repo.get_by_exam(
            student_id=tool_context.student_id,  # 👈 从上下文注入
            exam_id=args.get("exam_id")
        )
        
        if not report:
            return ToolResult(
                ok=False,
                error_code="REPORT_NOT_FOUND",
                data={}
            )
        
        # 3. 审计日志
        await self.audit_log.record(
            action="READ_DIAGNOSIS",
            student_id=tool_context.student_id,
            resource_id=report.id,
            allowed=True
        )
        
        return ToolResult(
            ok=True,
            data=report.structured_json,
            evidence=[
                EvidenceRef(
                    type="diagnosis_report",
                    resource_id=str(report.id),
                    label=report.exam.name,
                    as_of=report.generated_at
                )
            ]
        )
```

## 6. 数据模型

### 6.1 权益表

```sql
CREATE TABLE student_entitlements (
    id UUID PRIMARY KEY,
    school_id UUID NOT NULL,
    student_id UUID NOT NULL,
    product_code VARCHAR(50) NOT NULL,  -- 'DIAGNOSIS_REPORT'
    resource_type VARCHAR(50),          -- 'exam', 'subject', 'semester'
    resource_id UUID,                   -- 关联的资源ID
    status VARCHAR(20) NOT NULL,        -- 'active', 'expired', 'revoked'
    starts_at TIMESTAMP NOT NULL,
    expires_at TIMESTAMP,
    source_order_id VARCHAR(100),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    
    UNIQUE(student_id, product_code, resource_id),
    INDEX idx_student_product (student_id, product_code, status),
    INDEX idx_expiry (expires_at, status)
);
```

### 6.2 诊断报告表

```sql
CREATE TABLE diagnosis_reports (
    id UUID PRIMARY KEY,
    school_id UUID NOT NULL,
    student_id UUID NOT NULL,
    exam_id UUID,
    subject_id UUID,
    report_type VARCHAR(50) NOT NULL,   -- 'exam', 'subject', 'semester'
    status VARCHAR(20) NOT NULL,

    raw_content TEXT,

    version VARCHAR(20),

    updated_at TIMESTAMP DEFAULT NOW(),
    
    INDEX idx_student_exam (student_id, exam_id),

);
```

## 7. 权益查询服务

```python
class EntitlementService:
    async def check(
        self,
        student_id: UUID,
        product_code: str,
        resource_id: UUID | None = None
    ) -> Entitlement:
        """
        检查学生是否拥有指定权益
        """
        now = datetime.utcnow()
        
        query = (
            select(StudentEntitlement)
            .where(
                StudentEntitlement.student_id == student_id,
                StudentEntitlement.product_code == product_code,
                StudentEntitlement.status == 'active',
                StudentEntitlement.starts_at <= now
            )
        )
        
        if resource_id:
            query = query.where(
                or_(
                    StudentEntitlement.resource_id == resource_id,
                    StudentEntitlement.resource_id.is_(None)  # 全局权益
                )
            )
        
        query = query.where(
            or_(
                StudentEntitlement.expires_at.is_(None),
                StudentEntitlement.expires_at > now
            )
        )
        
        result = await self.db.execute(query)
        entitlement = result.scalar_one_or_none()
        
        return Entitlement(
            is_active=entitlement is not None,
            product_code=product_code,
            expires_at=entitlement.expires_at if entitlement else None,
            scope=entitlement.resource_type if entitlement else None
        )
    
    async def assert_allowed(
        self,
        student_id: UUID,
        product_code: str,
        resource_id: UUID | None = None
    ):
        """
        断言学生拥有权益，否则抛异常
        """
        entitlement = await self.check(student_id, product_code, resource_id)
        
        if not entitlement.is_active:
            raise EntitlementRequiredError(
                product_code=product_code,
                resource_id=resource_id
            )
```

## 8. 审计日志

### 8.1 所有拒绝都写日志

```python
await self.audit_log.record(
    action="READ_DIAGNOSIS",
    student_id=tool_context.student_id,

    allowed=False,
    reason="ENTITLEMENT_EXPIRED",
    metadata={
```

- 权益滥用检测

## 11. 关键要点总结

1. **权限在 Tool/Service 层强制执行，不依赖 Prompt**
2. **student_id/school_id 从认证上下文注入，模型无法指定**
3. **BASIC 只能看客观数据，不能获得诊断结论**
4. **DIAGNOSIS 只能解释已有报告，不能伪造新诊断**
5. **所有权限拒绝都写审计日志**
6. **权益检查必须验证资源归属和有效期**
