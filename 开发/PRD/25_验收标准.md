> 本文是放行门禁，不是完成报告。勾选项只有在附有可复现证据、环境和提交后才可标记通过。

## 1. 功能验收

### 1.1 学生主流程

- [ ] 登录成功后获取正确的 `user_id`、`school_id`、`student_id` 和角色。
- [ ] 创建会话、列出会话、读取历史消息和发送消息均使用正式 V2 路由。
- [ ] 成绩、排名、差值和趋势均由只读 Tool 计算，模型不得自行计算事实数字。
- [ ] 空数据、数据过期、Tool 错误和模型超时均返回稳定错误码。
- [ ] 每个 assistant 消息均包含 `agent_run_id`、数据批次和来源。

### 1.2 SSE 主流程

- [ ] POST SSE 流输出固定事件，并且每个事件带 `request_id`、`seq`、`data`。
- [ ] 前端按 `seq` 去重，能处理 `error`、`done`、取消和网络中断恢复。
- [ ] 刷新页面后会话和消息仍可读取，重复提交不会重复保存消息。

## 2. 安全与隐私门禁

- [ ] 匿名访问 Prompt、Trace、导入和管理接口返回 401。
- [ ] 角色和市—区—学校—班级—学生范围正确生效；跨学校读取返回 403 或统一 404。
- [ ] access token 不能用于 refresh；refresh 轮换、撤销和 logout 均有效。
- [ ] 生产启动拒绝默认/短密钥；镜像和日志不包含 `.env`、Token、密码或其他学生数据。
- [ ] 提示注入、错误信息泄露、敏感信息输出、限流和审计测试通过。

## 3. 数据与可追溯性门禁

- [ ] 空库 `alembic upgrade head` 成功，模型元数据、迁移和运行查询一致。
- [ ] 学校、学生、考试、成绩的复合归属约束和学校前缀索引有效。
- [ ] 同一 CSV/Excel 批次重复导入幂等，失败行隔离且可重试。
- [ ] 可根据 `agent_run_id` 查询 Prompt 版本、Tool 参数摘要、数据批次、模型用量、Guard 决策和最终消息。
- [ ] 数据保留、导出、删除和审计策略有实际演练记录。

## 4. 质量、性能与运维门禁

- [ ] 后端单元、PostgreSQL 集成、API 契约、前端构建、Playwright E2E 和安全测试在 CI 可重复运行。
- [ ] P0 缺陷为 0；P1 缺陷有明确豁免人、期限和回滚方案。
- [ ] 500、2000、5000 并发阶梯压测有结果，延迟、错误率、数据库连接和模型成本在预算内。
- [ ] Docker Compose 在全新主机可重建；健康检查、日志、告警、备份和恢复均验证。
- [ ] Nginx 正确支持 SSE 长连接；模型供应商故障可降级并可人工停用。

## 5. 证据记录模板

每项验收必须记录：

```text
验收项：
环境/版本：
执行命令或操作：
预期结果：
实际结果：
证据链接（日志、报告、截图或 CI）：
执行人/日期：
复核人/日期：
```

## 6. 放行规则

只有当功能、安全、数据、质量和运维五类门禁全部通过，且产品、安全、平台和学校试点负责人签字，状态才可从 `pilot_blocked` 变为 `pilot_ready`。`pilot_ready` 不等于全市正式上线；全市推广必须另行完成容量、隐私和市级运营验收。
