## 3. 源码复用优先级

### 3.1 四档分级

```text
第一档：OpenTutor、RAGFlow
    ↓ MIT / Apache 2.0，可重点复用
    
第二档：FastGPT / Dify
    ↓ Apache 2.0 + 附加，先核对使用方式
    
第三档：LearnHouse / SOLA / MaxKB
    ↓ AGPL / GPL，架构参考优先
    
禁止商业拷贝：SMART RAG / EduChat
    ↓ 明确禁止商业，仅思路参考
```

## 4. License 合规流程

### 4.1 使用前检查清单

每次真正复制第三方代码前：

- [ ] 确认当前 commit 的 LICENSE 文件
- [ ] 确认是否有额外 NOTICE / CONTRIBUTING 限制
- [ ] 确认是否有商业使用限制
- [ ] 确认是否有品牌/多租户限制
- [ ] 记录到 `THIRD_PARTY_NOTICES.md`

### 4.2 记录模板

创建 `docs/third-party/THIRD_PARTY_NOTICES.md`：

```markdown
# Third-Party Notices

## OpenTutor

- **Source**: https://github.com/zijinz456/OpenTutor
- **Commit**: abc123...
- **License**: MIT
- **Files Used**:
  - `services/agent/context_builder.py` → `app/agent/context_builder.py`
  - `services/llm/circuit_breaker.py` → `app/ai/circuit_breaker.py`
- **Modifications**: 简化了 Memory 加载逻辑
- **Purpose**: 学习 Context Builder 设计模式

---

## RAGFlow

- **Source**: https://github.com/infiniflow/ragflow
- **License**: Apache 2.0
- **Usage**: 独立部署为教材 RAG 服务，不复制代码
- **Integration**: 通过 REST API 集成

---
```

### 4.3 不允许的行为

❌ **禁止**：
- 复制 GPL/AGPL 代码到闭源商业项目
- 使用 SMART RAG / EduChat 的商业限制代码
- 删除原始 License 声明
- 不记录代码来源

## 6. Coding Agent 使用指引

### 6.1 正确的提问方式

✅ **正确**：
```text
请比较：
student-agent/app/agent/context_builder.py
与
reference-repos/OpenTutor/apps/api/services/agent/context_builder.py

只提取：
- ContextSource 解耦
- 并行获取
- Budget 控制
- Error isolation

不要复制：
- RAG 相关代码
- 长期 Memory
- TeachingState
```

❌ **错误**：
```text
把 OpenTutor 功能全抄过来。
```

### 6.2 防止盲目复制

要求 Coding Agent：
1. 先读代码，再提取设计思想
2. 找不到数据源就记录 TODO，不虚构字段
3. 每个 PR 只解决一个架构问题
4. 不增加未使用依赖
5. 不引入 Multi-Agent / RAG，除非当前阶段明确要求
6. 每完成一阶段更新文档
7. 不删除旧系统能力，除非迁移验证已经完成
