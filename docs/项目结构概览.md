# 项目结构概览

## 顶层目录

```text
智能问答助手/
├── apps/api/          FastAPI、Agent、数据模型、迁移和测试
├── apps/web/          React + TypeScript 前端
├── infra/nginx/       公共网关和 TLS 入口
├── infra/postgres/    PostgreSQL 初始化扩展
├── infra/scripts/     备份、恢复和健康检查
├── scripts/           本地测试、质量门禁和数据库初始化
├── docs/              当前运行/测试说明
├── 开发/PRD/          需求与验收门禁
└── docker-compose.yml Compose 编排（db/redis/api/web/nginx）
```

## 后端模块

```text
apps/api/app/
├── api/v1/endpoints/  auth、chat、health、prompts、traces
├── agent/             AgentLoop、IntentRouter、StudentContext
├── ai/                ModelGateway、fake/openai/deepseek Provider
├── core/              config、database、security、rate_limit、Trace、Guard
├── db/models/         school、user、student、exam、score、chat、agent 等
├── data/              CSV 校验、导入计划和同步服务
└── tools/             Tool 契约、注册表及成绩/考试分析 Tool
```

## Compose 网络

Nginx 是唯一公开入口；`api`、`web`、`db` 和 `redis` 只在
`app-network` 内通信。生产入口为 <http://localhost>，API 文档为
<http://localhost/docs>，健康检查为 <http://localhost/api/health>。

```bash
docker compose config
docker compose up -d --build
docker compose ps
```

./scripts/run_tests.sh
./scripts/run_quality.sh
