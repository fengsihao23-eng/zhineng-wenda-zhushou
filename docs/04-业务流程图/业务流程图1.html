首批闭环实施路径

数据盘点与契约

身份与考务接入

清洗师生、班级、任教、学科和考试，完成账号绑定。

门槛：身份不串、权限正确

成绩导入与发布

导入一个班一科一场考试，预检、对账后发布正式版本。

门槛：与原表逐项一致

分析与报告接入

核算班级指标、学生趋势，并绑定个人正式报告及原件。

门槛：缺项和样本量清楚

问答联合验收

页面、Tool、最终回答和依据逐条核对，覆盖更正与撤权。

结果：首批真实闭环签认

必须统一的业务规则

这些规则需要五模块和智能问答共同遵守。

规则 统一处理 问答表现
零分与缺项 有效零分、缺考、未录入、未评分分别存储；缺考不参加均分。 明确说明状态，不把空值回答成 0 分。
考试与学科范围 页面和 Tool 使用同一考试 ID、学科 ID；趋势以选定考试为截止。 不串到最新考试，不用总分替代单科。
班级统计 优先使用考试时班级快照；显示应考、实考、有效成绩和覆盖率。 当前学生问答不读取班级明细；教师问答另设授权。
报告选择 报告绑定学生、考试、学科、类型和版本；只有正式且受权的版本可读。 多份候选先选择，不能跨学科取“最新一份”代答。
更正与追溯 成绩更正和报告替换产生新修订，保留来源批次、时间和操作记录。 新问题读取新版本；历史回答保留当时事实和依据。
