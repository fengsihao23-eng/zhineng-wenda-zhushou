# 智能问答全链路流程图谱

交付文件：[`../智能问答_全链路流程图.html`](../智能问答_全链路流程图.html)。直接用浏览器打开即可，HTML 内置全部样式、脚本、图数据、字段字典和源码片段，不依赖服务器、CDN 或网络请求。单独复制 HTML 可以使用全部阅读与导出功能；“打开源码文件”链接需要保留仓库目录关系。

范围为截图中的师生班级与考试、成绩导入、班级分析、学生学情、正式报告原件，以及它们与学生智能问答的整个数据链路。基线是 2026-09-18 当前工作区源码（包括未提交实现），不是生产部署验收。

包含 16 个章节、32 张流程图、259 个节点、236 条连接、47 张数据表、484 个字段、99 个业务接口。提供节点详情、关联数据表跳转、全局搜索、图形缩放和平移、SVG 下载及全部内容打印为 PDF。第 14 章专门记录实际实现与设计口径的差异。

## 文件结构

- `build_atlas.py`：静态提取 ORM 字段、路由和源码证据，校验所有图中节点、边及表名，然后合成单文件 HTML。不会加载应用、读取 `.env` 或访问业务数据库。
- `domain_content.py`：总览、模块间数据流、教务与导入。
- `analysis_content.py`：班级分析、学生学情、报告原件。
- `qa_content.py`：问答、意图工具、事件流、依据回读。
- `reference_content.py`：原题与支持、CRUD、血缘、权限、字典说明和实现差异。
- `extra_diagrams.py`：导入状态机、实体关系和显式异常分支。
- `atlas.template.html`、`atlas.css`、`atlas.js`、`graphs.js`：页面模板、样式、阅读交互及原生 SVG 绘图。

重新生成：

```bash
python3 docs/04-业务流程图/flow-atlas/build_atlas.py
```

生成器不自动理解业务代码变化。源码更新后应先核对人工编写的流程说明，再重新生成；表结构、接口、引用片段和文件哈希会从当前源码提取。
