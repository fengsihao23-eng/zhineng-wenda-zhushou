# 智能问答业务流程图（业务版 2.0）

交付文件：[智能问答_业务流程图.html](../智能问答_业务流程图.html)。浏览器直接打开即可，离线可用，不依赖其他文件。

此版本根据“上一版偏数据结构，经理需要业务流程图”的反馈重做。内容组织从数据表、字段和接口，改为：

- 业务触发与办理目标。
- 教务管理员、成绩/报告负责人、系统、教师、学生等角色泳道。
- 具体办理动作、带条件的判断、工作交接、退回修正及结束结果。
- 每步所需和产出的业务资料名称，以及其对应问答用途。
- 区分平台操作、学校人工协作和目前没有办理入口的事项。

包含 10 个章节、20 张业务泳道图、245 个节点、41 处判断和 16 类业务资料。提供总业务流程；五个模块的办理场景；学生问答；反馈与人工处理；业务资料及问答用途；日常增删改路线。

既有《智能问答_全链路流程图.html》保留为技术参考，未覆盖。

## 生成方式

```bash
python3 docs/04-业务流程图/business-flow/build.py
```

`overview.py`、`school.py`、`scores.py`、`analysis.py`、`reports.py`、`chat.py`、`operations.py` 编写业务场景；`diagram.js` 生成泳道及避让活动框的连线；`app.js` 提供场景切换、节点详情、检索、缩放与导出；`style.css` 与 `template.html` 为样式和页面模板。

生成器检查节点位置、连接目标、子流程跳转、开始事件到所有步骤的可达性、所有步骤到完成事件的可达性，以及判断节点的分支标签。它不导入应用、不读取凭据、不操作业务数据库。
