## 界面与数据

- 管理端和小程序采用原件的 CSS、图标、显示模板、页签、抽屉与确认弹窗；以同源页面隔离样式，由 React 外壳接入当前认证。
- 原型中的 IndexedDB、硬编码档案、演示账号、模拟开关和本地规则引擎不进入正式运行代码。业务数据、版本、测试和留言均存入数据库，真实模型由既有后端网关调用。
- 原型桌面两侧为演示说明区。正式入口保留中间小程序界面，手机端铺满屏幕，桌面保留手机展示框；运营端接入项目既有导航。
- 模型、知识库接入和检索参数不向运营界面提供修改入口。
- 旧学生聊天提交接口在学校启用新工作台后返回升级提示，避免绕过新全校回答限制；未启用学校保留原契约。

## 数据边界

- 教师角色仅来自原型指定七项档案字段，兼任角色全部保留；说明与备注不生成角色。
- 所选角色只决定视角；教师/学生成绩及报告读取始终使用该账号的考试、科目、类型和对象授权。
- 报告按已保存考试归属；历史答复、所选上下文、来源和人工回复在重新读取时核对当前账号、授权、成绩内容摘要与报告版本。
- 初始化为本校实际适用学段生成“系统初始化安全基线”V1。后续任何人工发布必须完成当前草稿、另一类生效版本和各适用学段四类测试；初始内容不来自附件里的演示数据。
