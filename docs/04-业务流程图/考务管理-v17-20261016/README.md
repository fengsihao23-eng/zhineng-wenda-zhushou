# 考务管理需求基线（2026-10-16）

用户提供的对照文件为《考务管理_高保真原型.html》v17（2026-10-15）和《业务流程图_V1.html》r84（2026-10-13）。截图圈出“②考务管理”的两个子流程。

- 创建考试科目与范围：基本信息、科目与满分、考试学年班级记录、正常在读学生、分科名单、去重汇总、预览后原子保存。
- 考试成绩开放设置：运营管理员按考试为教师逐人配置内容、科目和学生范围，并独立为学生配置本人查询。
- v17 还包含完整名单成绩 Excel、动态小题列、原文件下载、删除重导、差异预览及操作记录。
- v17 最终学生控制界面支持运营管理员按科目开放或关闭；r84 文字写按整次考试。实现按较新的 v17 最终交互，操作人始终是运营管理员。
- 教师授权在保存时按科目冻结学生范围，角色和兼任标签不自动赋权。增加学生、科目或修改任教关系均不自动扩大已有考试权限。
