# 当前交付清单

本文列出仓库中可复核的交付物。`✅` 只表示文件或命令存在，不能替代功能、
安全和试点验收。

## 代码与运行

- ✅ `apps/api/app/api/v1/endpoints/`：认证、聊天、健康、Prompt、Trace 路由
- ✅ `apps/api/app/agent/`、`app/tools/`、`app/ai/`：Agent 主链路及工具
- ✅ `apps/api/app/db/models/` 和 `apps/api/alembic/`：模型与迁移
- ✅ `apps/web/src/`：登录、会话、SSE Chat 组件
- ✅ `docker-compose.yml`：`db`、`redis`、`api`、`web`、`nginx`
- ✅ `infra/nginx/`：HTTP 网关、SSE 配置、可选 TLS
- ✅ `infra/scripts/`：备份、恢复和健康检查

## 可复核命令

```bash
docker compose config
docker compose up -d --build
docker compose ps
./scripts/run_tests.sh
./scripts/run_quality.sh
```

测试默认使用 SQLite，CI 还运行 PostgreSQL 15；前端检查包括 lint、Vitest
和生产构建。详情见 [TESTING.md](TESTING.md)。

## 数据库初始化

API 容器启动时自动运行 Alembic。演示数据使用当前 ORM seed 脚本：

```bash
docker compose exec api python scripts/init_test_data.py
```

本脚本对 `DEMO_SCHOOL` 是幂等的；生产数据导入必须使用受控批次和隔离的
数据库连接。
