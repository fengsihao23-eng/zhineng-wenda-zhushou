# 知行：学生空间与教务工作台设计基线

本文件对应 2026-09-18 当前实现。保留知行品牌和已有成绩图表，作为新旧系统对齐后的增量设计基线。历史分析提及的根目录 `DESIGN.md` 当前不存在，因此新建此文档，不覆盖旧规范。

## 1. 全局

- 正文、表格、表单使用系统中文无衬线字体；表格数字使用等宽数字。
- 内容区白色与中性浅灰；靛蓝为主要操作与导航色。侧栏保留品牌识别，取消大面积紫色侧栏渐变。已有图表的轴、配色语义和未知满分逻辑保留。
- 主导航统一使用项目内 SVG 图标，配文字，不再混用 emoji。状态必须显示文字；成功、待处理、错误/关闭分别有语义色。
- 管理导航分为业务生产、教学分析、运营治理。学生保留现有可用书签 `/profile`、`/trends`、`/diagnosis`、`/mistakes` 等。
- 新表格使用同一个容器、工具栏、分页、状态和错误组件。工作区内容允许纵向滚动，直接子面板和表格不被 flex 压缩到不可点击。

## 2. 页面结构

| 场景 | 固定顺序 |
|---|---|
| 学校主数据 | 学校范围说明 → 对象标签 → 搜索与新建 → 表格/分页 → 当前记录维护与账号绑定 |
| 导入 | 上传 → 固定批次 → 映射/模板 → 文件/行/字段错误 → 核对确认 → 真实任务状态 → 事务回执 |
| 试卷 | 列表 → 受权原件上传 → 考试学科绑定 → 不可变原件版本 → 拆题 |
| 拆题 | 区域列表、原图、属性三栏；先保存草稿，再 OCR/人工编辑，再确认发布 |
| 题库 | 学科/类型/标题/回收站筛选 → 层级与父子详情 → 版本正文/解析/标签 → 人工发布/引用检查 |
| 学生复习 | 考试失分事实 → 正式版本原题/解析 → 订正 → 自评状态与下次时间 → 历史记录 |
| 人工服务 | 当前状态/处理人 → 双向消息 → 补充问题/回复 → 处理记录 → 带原因确认或重开 |
| 回答依据 | 阅读回答 → 点击业务来源 → 固化事实/版本 → 重新受权核验；不把工具 JSON 展示为默认回答 |

首版原生生产按学校范围运行。教师页默认匿名汇总和样本量，下钻时才按任教授权展示个体，并记录访问。

## 3. 状态与可恢复性

- 加载、无数据、无权限、请求失败、重复提交与成功回读是组件契约。
- 只有收到服务端成功并重新读取后才显示保存结果。导入/识别进度使用真实阶段或最终计数，不显示假进度条。
- 写入中禁用相应按钮；错误重试保留提交键/内容；后端同时处理幂等和冲突。
- 原件缺失、题目未映射、报告无权益、OCR 未配置分别解释。不存在资料时不生成假题目、假原件或假诊断。
- 草稿冲突显示明确错误，允许保留当前内容核查，或主动放弃本地修改并重读。人工确认总是绑定当前已保存修订。
- 文件以受权 Blob 预览，关闭和组件卸载时撤销临时 URL，不在地址栏附带登录凭据。

## 4. 移动端和键盘

- 850px 以下主导航使用抽屉，关闭时释放内容宽度；支持遮罩关闭和 Escape。
- 学生页和管理列表在 320/390/768/1440px 验收，无页面级横向溢出。宽表在自身容器内滚动，不能裁掉操作列。
- 手机只读查看拆题原件/草稿，桌面提供编辑和发布。区域也可通过键盘新增、输入归一化坐标，不依赖拖动唯一操作。
- 所有表单有明确可访问名称，保留焦点环和中文输入法回车处理。状态不只靠颜色，重要结果用 `role=status` 告知。
- 回答 Markdown 禁用原始 HTML/远程图片/模型生成导航，公式 `trust=false`；公式和代码可以在局部横向滚动。

## 5. 当前范围

本轮完成共同视觉语言和新增工作台组件，未将已有成绩概览与趋势图强行合并为一套新图表实现，以保留已验证的双轴/雷达与响应式行为。既有学生首页、成绩概览、趋势页仍可分别访问；进一步信息架构收敛应作为单独迭代验收。
