# Profile.tsx 成绩概览页面文档

## 概述

Profile.tsx 是学生成绩概览页面，提供了可视化的成绩展示和趋势分析功能。

## 功能特性

### 1. 最近考试成绩卡片
- 显示最近一次考试的总分、满分、得分率
- 展示与上次考试的分数变化（delta）
- 显示班级排名和年级排名
- 渐变色背景设计，视觉突出

### 2. 成绩趋势图表
- 使用 Recharts LineChart 展示多次考试的总分趋势
- 双折线图：总分（实线）+ 得分率（虚线）
- 交互式 Tooltip，显示详细数据
- 自动适应数据范围

### 3. 学科雷达图
- 使用 Recharts RadarChart 展示各科目得分率
- 直观对比不同科目的表现
- 下方列表展示详细的科目成绩和排名
- 进度条可视化得分率

### 4. 数据管理
- 使用 TanStack Query 进行数据缓存
- 缓存时间：5分钟 (staleTime)
- 自动重试机制
- 加载状态和错误处理

## API 集成

### 数据源

1. **仪表盘数据**: `/platform/student/dashboard`
   - 学生信息
   - 最近考试成绩
   - 科目表现
   - 考试数量统计

2. **趋势数据**: `/platform/student/trends`
   - 历史考试记录
   - 科目趋势数据
   - 排名变化

### 缓存策略

```typescript
staleTime: 5 * 60 * 1000,  // 5分钟
gcTime: 10 * 60 * 1000,     // 10分钟
refetchOnWindowFocus: false,
retry: 1
```

## 路由配置

- **路径**: `/profile`
- **导航位置**: 学生空间菜单第二项
- **图标**: 📊
- **标签**: "成绩概览"

## 响应式设计

### 桌面端 (> 1024px)
- 两栏布局：主内容区 + 侧边栏
- 成绩卡片和趋势图在左侧
- 雷达图在右侧

### 平板端 (640px - 1024px)
- 单栏布局
- 组件垂直排列

### 移动端 (< 640px)
- 压缩内边距
- 字体大小调整
- 按钮全宽显示

## 组件结构

```
ProfilePage (主容器)
├── LoadingState (加载状态)
├── ErrorState (错误状态)
└── 正常状态
    ├── profile-header (页面头部)
    │   ├── 学生名称和统计
    │   └── 快捷操作按钮
    ├── profile-grid (主网格)
    │   ├── profile-grid__main
    │   │   ├── ScoreCard (成绩卡片)
    │   │   └── TrendChart (趋势图)
    │   └── profile-grid__sidebar
    │       └── SubjectRadar (雷达图)
    └── profile-footer (页面底部)
        └── 数据同步状态
```

## 性能优化

1. **数据缓存**: 使用 TanStack Query 减少 API 调用
2. **懒加载**: 图表库按需加载
3. **响应式图表**: ResponsiveContainer 自动适配
4. **状态管理**: 最小化重渲染

## 使用示例

### 访问页面
1. 学生登录系统
2. 点击左侧导航 "成绩概览"
3. 或直接访问 `/profile`

### 查看趋势
- 点击 "查看详细趋势" 按钮跳转到 `/trends` 页面

### 咨询助手
- 点击 "问问学习助手" 按钮跳转到 `/chat` 页面
