## 1. 项目概览

### 1.1 项目定位

**市级学生智能问答助手** 是一个基于真实校务数据的多租户SaaS平台，通过AI Agent技术为学生提供个性化的学业数据查询和诊断服务。

### 1.2 核心价值

- **数据准确性**: 使用确定性代码计算而非LLM推理，保证数值准确性
- **权限隔离**: 学生只能访问自己的数据，严格的租户隔离
- **分层服务**: BASIC（免费，仅客观数据）/ DIAGNOSIS（付费，含学习诊断）
- **完整追溯**: 每次对话都有证据链和工具调用记录

### 1.3 演进路线

```
V1 (当前): 成绩问答 + 基础诊断
V2-V3:    知识库问答 + RAG集成
V4-V5:    错题本 + 个性化推荐
V6-V8:    长期记忆 + 智能辅导
```

## 3. 系统架构

### 3.1 整体架构图

```
┌─────────────────────────────────────────────────────────────┐
│                         Nginx Gateway                        │
│                   (Routing + Rate Limiting)                  │
└────────────────┬────────────────────────────┬────────────────┘
                 │                            │
        ┌────────▼────────┐          ┌────────▼────────┐
        │   React Frontend │          │  FastAPI Backend │
        │   (Port 3000)    │          │   (Port 8000)    │
        └──────────────────┘          └────────┬─────────┘
                                               │
                    ┌──────────────────────────┼──────────────────────────┐
                    │                          │                          │
           ┌────────▼─────────┐    ┌──────────▼───────────┐   ┌─────────▼─────────┐
           │  PostgreSQL 15   │    │     Redis Cache      │   │   Model Gateway   │
           │   + pgvector     │    │  (Prompt + Session)  │   │ (DeepSeek/OpenAI) │
           └──────────────────┘    └──────────────────────┘   └───────────────────┘
```

### 3.2 核心架构原则

#### 3.2.1 轻量级Agent设计

**选择**: Single-loop Agent with Tool Calling  
**放弃**: Multi-Agent Orchestration

```python
# Agent工作流
User Query 
  → Intent Router (规则路由)
  → Context Builder (加载学生上下文)
  → Tool Execution (先执行工具获取数据)
  → Model Generation (基于工具结果生成回答)
  → Response Guard (验证权限和事实)
  → SSE Stream (流式返回)
```

**优势**:
- 可预测性强，便于调试
- 成本可控（减少不必要的模型调用）
- 响应速度快（工具优先）

#### 3.2.2 数据流设计

```
1. 认证层: JWT Token → User Identity
2. 权限层: RBAC + Entitlement Check
3. 数据层: Student Context Loading (Lazy Load)
4. 计算层: Deterministic Tools (Python Code)
5. 生成层: Model Gateway (Multi-provider)
6. 校验层: Response Guard (Facts + Permissions)
7. 追溯层: Trace Logs (agent_run_id)
```

#### 3.2.3 多租户隔离

- **数据库层**: tenant_id字段强制隔离
- **应用层**: SQLAlchemy Filter自动注入
- **API层**: Dependency Injection校验租户身份
- **前端层**: 路由守卫 + Context限制

## 6. 数据库设计

### 6.1 核心表结构

#### 6.1.1 用户与权限

```sql
-- 用户表
CREATE TABLE users (
    id UUID PRIMARY KEY,
    username VARCHAR(100) UNIQUE NOT NULL,
    hashed_password VARCHAR(255) NOT NULL,
    role VARCHAR(50) NOT NULL,  -- STUDENT/TEACHER/SCHOOL_ADMIN/SUPER_ADMIN
    school_id UUID REFERENCES schools(id),
    student_id UUID REFERENCES students(id),  -- 如果是学生
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 角色表
CREATE TABLE roles (
    id UUID PRIMARY KEY,
    name VARCHAR(50) UNIQUE NOT NULL,
    permissions JSONB NOT NULL,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 学校表（多租户）
CREATE TABLE schools (
    id UUID PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    province VARCHAR(50),
    city VARCHAR(50),
    district VARCHAR(50),
    settings JSONB DEFAULT '{}',
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW()
);
```

#### 6.1.2 学生与考试数据

```sql
-- 学生表
CREATE TABLE students (
    id UUID PRIMARY KEY,
    school_id UUID REFERENCES schools(id) NOT NULL,
    student_code VARCHAR(50) NOT NULL,
    name VARCHAR(100) NOT NULL,
    grade VARCHAR(20),
    class_name VARCHAR(50),
    gender VARCHAR(10),
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(school_id, student_code)
);

-- 考试表
CREATE TABLE exams (
    id UUID PRIMARY KEY,
    school_id UUID REFERENCES schools(id) NOT NULL,
    exam_code VARCHAR(100) NOT NULL,
    exam_name VARCHAR(200) NOT NULL,
    exam_type VARCHAR(50),
    grade VARCHAR(20),
    exam_date DATE,
    total_score DECIMAL(10,2),
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(school_id, exam_code)
);

-- 科目表
CREATE TABLE subjects (
    id UUID PRIMARY KEY,
    school_id UUID REFERENCES schools(id) NOT NULL,
    subject_code VARCHAR(50) NOT NULL,
    subject_name VARCHAR(100) NOT NULL,
    category VARCHAR(50),
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(school_id, subject_code)

-- 考试-科目关联
CREATE TABLE exam_subjects (
    id UUID PRIMARY KEY,
    exam_id UUID REFERENCES exams(id) NOT NULL,
    subject_id UUID REFERENCES subjects(id) NOT NULL,
    full_score DECIMAL(10,2) NOT NULL,
    weight DECIMAL(5,2) DEFAULT 1.0,
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(exam_id, subject_id)
);
```
