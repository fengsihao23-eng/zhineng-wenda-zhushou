## 2. 单元测试 (Unit Tests)

### 2.1 覆盖范围

- Repository 层（数据访问）
- Service 层（业务逻辑）
- Tool 层（工具函数）
- Utility 函数

### 2.2 示例

```python
import pytest
from unittest.mock import Mock, AsyncMock

async def test_student_repository_get():
    """测试 StudentRepository.get()"""
    
    # Arrange
    mock_db = AsyncMock()
    mock_db.execute.return_value.scalar_one_or_none.return_value = StudentModel(
        id=uuid4(),
        name="张三",
        student_no="2024001"
    )
    
    repo = StudentRepository(mock_db)
    
    # Act
    student = await repo.get(student_id)
    
    # Assert
    assert student.name == "张三"
    assert student.student_no == "2024001"

async def test_entitlement_service_check():
    """测试权益检查"""
    
    service = EntitlementService(mock_db)
    
    # 有权益
    entitlement = await service.check(
        student_id=student_id,
        product_code="DIAGNOSIS_REPORT"
    )
    assert entitlement.is_active == True
    
    # 无权益
    entitlement = await service.check(
        student_id=other_student_id,
        product_code="DIAGNOSIS_REPORT"
    )
    assert entitlement.is_active == False
```

## 3. 集成测试 (Integration Tests)

### 3.1 API 集成测试

```python
from httpx import AsyncClient

@pytest.fixture
async def client():
    async with AsyncClient(app=app, base_url="http://test") as ac:
        yield ac

async def test_chat_flow(client: AsyncClient):
    """测试完整对话流程"""
    
    # 1. 登录
    response = await client.post("/api/v1/auth/login", json={
        "username": "student_001",
        "password": "password"
    })
    assert response.status_code == 200
    token = response.json()["access_token"]
    
    # 2. 创建会话
    response = await client.post(
        "/api/v1/chat/sessions",
        headers={"Authorization": f"Bearer {token}"}
    )
    session_id = response.json()["id"]
    
    # 3. 发送消息
    response = await client.post(
        f"/api/v1/chat/sessions/{session_id}/messages",
        headers={"Authorization": f"Bearer {token}"},
        json={"content": "我这次考得怎样？"}
    )
    assert response.status_code == 200
    assert "总分" in response.json()["content"]
```

## 4. E2E 测试 (End-to-End)

### 4.1 Playwright 测试

```python
from playwright.async_api import async_playwright

async def test_complete_user_flow():
    """测试完整用户流程"""
    
    async with async_playwright() as p:
        browser = await p.chromium.launch()
        page = await browser.new_page()
        
        # 1. 登录
        await page.goto("http://localhost:3000/login")
        await page.fill('[name="username"]', 'student_001')
        await page.fill('[name="password"]', 'password')
        await page.click('button[type="submit"]')
        
        # 2. 等待跳转到首页
        await page.wait_for_url("**/dashboard")
        
        # 3. 进入 Chat
        await page.click('text=智能问答')
        await page.wait_for_selector('.chat-container')
        
        # 4. 发送消息
        await page.fill('.input-box__textarea', '我这次考得怎样？')
        await page.click('.input-box__send')
        
        # 5. 等待回复
        await page.wait_for_selector('.message--assistant')
        
        # 6. 验证回复
        answer = await page.text_content('.message--assistant .message__text')
        assert '总分' in answer
        assert '排名' in answer
        
        await browser.close()
```

```python
import yaml

@pytest.mark.parametrize("test_case", load_test_cases())
async def test_agent_qa(test_case):
    """Agent QA 回归测试"""
    
    response = await agent.ask(
        student_id=test_case["student_id"],
        query=test_case["query"]
    )
    
    # 检查包含
    for keyword in test_case.get("expected_contains", []):
        assert keyword in response.text, f"Expected '{keyword}' in answer"
    
    # 检查不包含
    for keyword in test_case.get("expected_not_contains", []):
        assert keyword not in response.text, f"Unexpected '{keyword}' in answer"
    
    # 检查 Tool 调用
    tool_names = [t.tool_name for t in response.tool_calls]
    for tool in test_case.get("expected_tools", []):
        assert tool in tool_names, f"Expected tool '{tool}' to be called"
    
    for tool in test_case.get("expected_tools_not_called", []):
        assert tool not in tool_names, f"Tool '{tool}' should not be called"
```

## 6. Mock LLM

### 6.1 为什么需要 Mock

- 单元测试不依赖真实模型
- 测试速度快
- 测试结果可预测
- 节省成本

### 6.2 Mock 实现

## 11. 关键要点

1. **单元测试为主（70%），集成测试为辅（20%），E2E 测试少量（10%）**
2. **Agent 回归测试使用固定数据集**
3. **Mock LLM 用于单元测试，节省成本**
4. **覆盖率目标 > 80%**
5. **CI/CD 自动运行测试**
6. **性能测试定期执行**
