## 2. 认证 (Authentication)

### 2.1 JWT Token

**Access Token**:
- 有效期：1 小时
- 包含：user_id, student_id, school_id, roles

**Refresh Token**:
- 有效期：30 天
- 只能用于刷新 Access Token

### 2.2 Token 生成

```python
from jose import jwt
from datetime import datetime, timedelta

def create_access_token(user: User) -> str:
    """创建 Access Token"""
    
    payload = {
        "sub": str(user.id),
        "student_id": str(user.student_id),
        "school_id": str(user.school_id),
        "roles": user.roles,
        "exp": datetime.utcnow() + timedelta(hours=1),
        "iat": datetime.utcnow(),
        "type": "access"
    }
    
    return jwt.encode(payload, SECRET_KEY, algorithm="HS256")
```

### 2.3 Token 验证

```python
async def get_current_user(token: str = Depends(oauth2_scheme)) -> User:
    """验证 Token 并获取当前用户"""
    
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        
        if payload.get("type") != "access":
            raise HTTPException(401, "Invalid token type")
        
        user_id = payload.get("sub")
        if not user_id:
            raise HTTPException(401, "Invalid token")
        
        user = await user_repo.get_by_id(UUID(user_id))
        if not user:
            raise HTTPException(401, "User not found")
        
        return user
        
    except JWTError:
        raise HTTPException(401, "Invalid token")
```

## 3. 授权 (Authorization)

### 3.1 数据隔离

**核心原则**：
> 学生只能访问自己学校、自己的数据

**实现**：
```python
# Middleware 注入 school_id / student_id
@app.middleware("http")
async def inject_scope(request: Request, call_next):
    if current_user := getattr(request.state, "user", None):
        request.state.school_id = current_user.school_id
        request.state.student_id = current_user.student_id
    
    return await call_next(request)

# Repository 自动过滤
class StudentRepository:
    async def list_exams(self, student_id: UUID) -> list[Exam]:
        """自动加 school_id 过滤"""
        query = (
            select(Exam)
            .join(StudentExamScore)
            .where(
                StudentExamScore.student_id == student_id,
                Exam.school_id == self.current_school_id  # 👈 自动注入
            )
        )
        return await self.db.execute(query)
```

### 3.2 RBAC

```python
from enum import Enum

class Permission(str, Enum):
    READ_OWN_SCORE = "read_own_score"
    READ_DIAGNOSIS = "read_diagnosis"
    MANAGE_STUDENTS = "manage_students"

# 权限装饰器
def require_permission(permission: Permission):
    def decorator(func):
        async def wrapper(*args, **kwargs):
            current_user = kwargs.get("current_user")
            if not has_permission(current_user, permission):
                raise HTTPException(403, "Permission denied")
            return await func(*args, **kwargs)
        return wrapper
    return decorator

# 使用
@router.get("/diagnosis")
@require_permission(Permission.READ_DIAGNOSIS)
async def get_diagnosis(...):
    pass
```

## 4. 输入验证

### 4.1 Pydantic 验证

```python
from pydantic import BaseModel, validator

class ChatMessageRequest(BaseModel):
    content: str
    
    @validator('content')
    def content_not_empty(cls, v):
        if not v.strip():
            raise ValueError('内容不能为空')
        return v.strip()
    
    @validator('content')
    def content_length(cls, v):
        if len(v) > 1000:
            raise ValueError('内容过长')
        return v
```

### 4.2 SQL Injection 防御

**正确**（使用参数化查询）:
```python
# ✅ 使用 SQLAlchemy
result = await db.execute(
    select(Student).where(Student.id == student_id)
)

# ✅ 使用参数化
result = await db.execute(
    text("SELECT * FROM students WHERE id = :id"),
    {"id": str(student_id)}
)
```

**错误**（字符串拼接）:
```python
# ❌ 禁止
query = f"SELECT * FROM students WHERE id = '{student_id}'"
```

## 5. Prompt Injection 防御

### 5.1 工具层防御

**关键原则**：
> 权限在 Tool/Service 层强制执行，不依赖 Prompt

```python
class GetDiagnosisTool:
    async def execute(self, context, args):
        # 1. 强制权限检查（不管 Prompt 怎么写）
        if context.entitlement_level != "DIAGNOSIS":
            raise EntitlementRequiredError()
        
        # 2. student_id 从 context 注入（不接受 args）
        report = await self.repo.get_report(
            student_id=context.student_id,  # 👈 强制注入
            exam_id=args.get("exam_id")
        )
        
        return report
```

### 5.3 输出过滤

```python
class ResponseGuard:
    async def validate(self, answer: str, context) -> str:
        """输出过滤"""
        
        # 检查是否泄漏其他学生信息
        if self._contains_other_student_info(answer, context):
            raise SecurityError("Response contains other student info")
        
        # 检查是否输出内部信息
        forbidden_keywords = ["SQL", "Token", "password", "API Key"]
        if any(kw in answer for kw in forbidden_keywords):
            raise SecurityError("Response contains sensitive info")
        
        return answer
```

## 6. 数据隐私

### 6.1 敏感信息脱敏

```python
def mask_student_no(student_no: str) -> str:
    """脱敏学号"""
    if len(student_no) <= 4:
        return student_no
    return student_no[:2] + "****" + student_no[-2:]

def mask_phone(phone: str) -> str:
    """脱敏手机号"""
    return phone[:3] + "****" + phone[-4:]
```

### 6.2 日志脱敏

```python
class SensitiveDataFilter:
    """日志敏感数据过滤"""
    
    def filter(self, log_dict: dict) -> dict:
        """过滤敏感字段"""
        
        sensitive_fields = ["password", "token", "api_key"]
        
        for key in sensitive_fields:
            if key in log_dict:
                log_dict[key] = "***REDACTED***"
        
        return log_dict
```

## 8. HTTPS / TLS

### 8.1 Nginx TLS 配置

```nginx
server {
    listen 443 ssl http2;
    server_name example.com;
    
    # TLS 证书
    ssl_certificate /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;
    
    # TLS 协议
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    
    # HSTS
    add_header Strict-Transport-Security "max-age=31536000" always;
    
    # 其他安全头
    add_header X-Frame-Options "DENY" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    
    location / {
        proxy_pass http://api:8000;
    }
}
```
