## 3. 已核实的公开价格与计算

以下是官方公开单价或据其计算的示例，未计账号折扣及未来调价。它们不是整套系统的最终报价。

### 3.1 CLB网络费

广州包月固定带宽，超过5Mbps的公开计算式为 `125 + 80 ×（带宽Mbps - 5）` 元／月；按使用流量的公开单价为0.8元／GB，按1024GB换算1TB。对应如下：[腾讯云网络费用](https://cloud.tencent.com/document/product/214/42935)

| 计费场景 | 仅网络费用 |
| --- | ---: |
| 包月固定20Mbps | 1325.00元／月 |
| 包月固定50Mbps | 3725.00元／月 |
| 按流量，月出流量1TB | 819.20元 |
| 按流量，月出流量3TB | 2457.60元 |

固定带宽与流量按实际计费模式选择，不把两种网络费用同时相加。设置按流量方案的带宽上限，不等于购买固定带宽月包；应核对峰值可用性、超限处理及实测表现，再确定计费模式。

### 3.2 CLB实例与LCU费

广州公开实例费为0.2元／小时，包月实例费为144元。性能容量型还收取LCU费用；官方列出的包月标准型LCU费为423.36元／月。因此，在这些公开价格均适用、无额外费用和优惠的情况下，包月标准型CLB配20Mbps的合计示例为 `144 + 423.36 + 1325 = 1892.36元／月`，配50Mbps为 `4292.36元／月`。按量LCU费用需要用实际连接和流量计算。[实例费](https://cloud.tencent.com/document/product/214/8848)、[LCU费用](https://cloud.tencent.com/document/product/214/58387)

上述CLB金额不含CVM、数据库、Redis、COS、CDN、模型或其他资源费用。每月天数影响按小时计费金额，表内包月实例与LCU金额采用官方公布的包月价。

## 5. 稳定性验收约束

这些是待验证的上线门槛：

1. 两台应用分别部署在不同可用区，任意一台退出后，另一台或已验证的自动扩容流程仍能承接约定峰值；若4核8GB单台不能达到目标，使用备选8核16GB或增加节点。不能只测两台同时正常。
2. 数据库进行真实主备切换及备份恢复演练，核对应用重连、已提交问答／配额及幂等状态；恢复时间与可恢复点目标在实际数据量和云产品能力确认后定稿。
3. Redis失效时业务的限流、排队、凭据撤销与缓存降级行为明确；成绩和配额事实不依赖可丢失缓存。
4. 按1000在线、约20次问答／秒及状态同步、报告访问、管理员操作的混合场景记录吞吐、P95/P99、业务成功率、连接池及模型在途数。
5. 数据库长事务、全量状态读取、模型并发控制及PDF处理隔离完成后再做容量验收；当前生产单机功能通过不能作为这一门槛已完成的证明。
6. 域名、HTTPS、网站与小程序备案分别完成相应环节；真机关闭域名调试豁免后验证。
