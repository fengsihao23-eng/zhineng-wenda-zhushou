# 超管与学校管理分离

现有 `admin` 保留阳江高级中学的学校管理员身份，进入原有教师档案、学生档案、考务管理、报告管理、提示词及人工五个模块。学校主档使用名称「阳江高级中学」、编码 `441702004001`；学校、管理员和业务记录的内部 ID 保持原值。

独立超管只进入「管理员与操作历史」，可管理学校管理员账号、所属学校、权限、密码和相关记录。登录验证后的 API 权限会阻止超管访问业务模块，即使旧账号曾同时拥有其他角色。学校名称和编码筛选仍用于管理员列表和历史，不作为切换业务学校的入口。操作历史保留操作摘要，管理员变更保留前后对照，业务数据内容不通过超管历史返回。

上线不需要数据库架构变更。先备份数据库，暂停 API，执行 `apps/api/scripts/separate_platform_admin.py --phase prepare` 建立独立账号。用新代码验证该账号的登录、管理员模块和业务接口拒绝，成功后执行 `--phase finalize`：同一事务中对齐学校主档、撤销原 `admin` 的超管角色并使旧登录会话失效，新超管首次正式登录需要修改初始密码。原 `admin` 的密码不变，原账号和数据不重建。

凭据文件仅供账号持有人私下领取，文件权限为 `0600`，密码不写入 Git、发布日志或操作历史。
