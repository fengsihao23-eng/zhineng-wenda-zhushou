# 学生档案 r79 原型与流程对齐

2026-10-12。页面依据用户提供的《学生档案页_高保真原型.html》（v1，2026-10-10）；业务依据《业务流程图_V1(1).html》「维护教师 / 学生档案」第 3–8 个页签。

## 页面与办理入口

学生页保留原型的五个页签、信息列表、姓名/账号/学号检索、班级与状态筛选、分页和勾选。顶部提供升级/换班、档案变更、批量离校/毕业、批量误导入删除、操作记录及导入学生。正常、离校、毕业显示不同状态及对应入口；档案抽屉显示完整 31 列，8 个锁定字段标红，学情与历史记录可以查看。

旧导入、回执等页面路由转到统一学生页的弹窗/抽屉。旧通用编辑和生命周期快捷接口拒绝绕过核验与确认；已有外部数据及其绑定接口保留。

## 六个流程

| 页签 | 处理与约束 |
| --- | --- |
| 3. 新增导入 | 30 列表头与顺序严格一致，r79 的 mac地址、SN码不带旧模板末尾空格。姓名、账号必填，账号在学生账户空间及文件内唯一，状态仅接受正常。其他字段保留填写值，不新增字典或格式要求。已有学生与文件内所有同班同名行均提醒；逐行保留或放弃，整批提交。创建独立学生ID和账号，初始密码等于账号，首次登录强制修改。 |
| 4. 档案变更 | 导出所选正常学生原值，未勾选时可导出当前筛选下全部正常学生。31 列＝30 列＋学生ID；学校编号、学校名称、姓名、账号、年级、班级、状态、学生ID锁定，23 个普通字段可改。重复ID列出全部重复行，任一错误整批退回；预览仅列变化及清空项，二次确认后写入。 |
| 5. 升级/换班 | 使用学生ID、账号、姓名、目标年级、目标班级号五列，后两列使用完整名称。当前学年只处理上传名单；下一学年须核实实际毕业名单，毕业均办结，留级等非毕业候选注明剔除依据，正常在读名单全部覆盖。按学生ID＋学年新增/更新；异常年级逐人填写复核依据并审批。全校下一学年办理成功才切换当前学年。 |
| 6. 离校办理 | 每批仅一种类型、一个办理学年。离校/毕业仅正常学生，毕业还须为该学年毕业年级并核对实际名单。账号停用，历史保留；毕业归档。恢复沿用原学生ID、账号、密码，同学段返校，当前/下一学年记录与账号启用同时提交；不切换全校学年，也不要求全校毕业和名单前置检查。旧休学、退学状态在页面统一归入离校并可恢复。 |
| 7. 误导入删除 | 按原型只办理正常状态下已核实的误导入/多余记录，混入离校或毕业记录整批退回。重复类型须指定更早创建、已核实有效且不在删除名单的保留记录。展示个人数据类型/条数、参加的考试、对应班级年级和重算范围。二次确认后删除账号、档案、学年记录与个人数据及其后代，保留考试、班级、其他学生；仅更新受影响考试中的对应班级/年级统计及相关报告统计。长期保存原档案、原账号、导入批次、核验、影响范围和处置结果，释放账号。 |
| 8. 姓名/账号变更 | 仅正常学生、单条、每次一项，填写原因。学生账号空间独立于教师/家长；新姓名同班同名须确认。原学生ID和历史关系不变，账号变更立即令旧会话失效，原密码保留，新账号接管。 |

身份存疑均进入当前事项持久化待审核任务。审核期间无学生数据写入，通过后回原任务继续，拒绝则结束。已经提交审核的记录不能靠重新勾选「已确认」绕过审核。

## 数据一致性与历史

迁移 `019_student_r79_workflows` 新增全校当前学年、毕业归档时间、学生学年记录、考试归属快照与办理任务。迁移本身不改人员、成绩、账号和既有记录；存在办理/历史数据时禁止直接降级丢弃。

所有确认在学校及任务锁内复校验后整批事务提交，保留原值指纹防止并发覆盖；重复确认返回同一结果，并发确认只产生一次更新和一次确认日志。换班前固定既有考试归属，新成绩同步也保存归属；班级分析与教师成绩范围使用考试发生时的归属。删除后的排名保留并列规则，仅更新影响范围内的班级/年级，原报告及文件保留原文，重算统计另存为报告附加数据。

普通字段使用完整存储容量；学生学号、年级、班级不因新增的学年表被额外截断。超过 bcrypt 72 字节的初始账号密码使用 bcrypt_sha256，验证兼容旧 bcrypt，并校验密码全部 UTF-8 字节。正式、已绑定档案的学生账户不会因恰好使用开发示例名称而无法首登，首次改密和开发示例学校/旧示例账户保护仍有效。

新上传原文件完整保存、可下载；旧批次缺失原文件时明确说明，并提供已保存的 30 列原始资料，不伪造原文件。公开验收材料只使用合成数据，私有教师/学生样例工作簿、密钥、凭据、线上数据和发布日志不入库。
