# 新旧系统对齐：核心业务实施与验收

日期：2026-09-18。基于当前新系统和工作区已有 M0 修改继续增量实现。已完整阅读用户指定的四份文档；旧产物仅作业务语义与交互参考，没有复制旧实现。

本轮交付覆盖教务生产、学生复习、教师分析、人工服务和问答证据的核心操作路径，已在隔离环境完成 API 与浏览器验收。**这不等于路线图 M1–M5 全部完成，也不等于旧后台可停用或已经生产上线。**

状态口径：

- **真实实现**：已有持久化、服务权限、产品入口和本轮隔离验证；不代表生产容量或学校业务签认。
- **局部实现**：表中明确指出完整路线卡尚缺的部分，不上调为旧系统全面替代。
- **Mock**：仅 QA 的 Fake Model Provider、合成学校/试卷和受控故障响应；新业务读写没有用 Mock 数据冒充成功。OCR 浏览器旅程使用实际 Tesseract。
- **占位**：本轮核心入口没有新增伪成功操作；缺原件/缺题目/缺引擎明确阻断或显示缺件。既有 RAG、家长门户和 M5 高级能力没有因此变成已完成。
- **仅有接口**：`POST /platform/education/scores/{id}/question` 提供管理员补绑旧得分的接口，没有独立的逐题补绑页面；已交付的 CSV 和旧快照链路可直接完成明确版本关联。

## 2. 保留与增量方式

保留了新系统鉴权、租户隔离、教师任教策略、诊断权益、共享凭据撤销、确定性成绩 Tool、会话/取消/重试、Trace、Prompt 版本、Response Guard、CSV 事务 staging 和身份隔离缓存。没有替换 Agent 架构，也没有启用 RAG 或复杂多 Agent。

对既有代码的主要增量：

- `CsvImportService.apply_validated_plan` 让受权工作台在自身事务中调用原写入内核。
- 小题成绩新增正式题目版本关联，旧字段保持兼容；旧不明 UUID 不自动猜配。
- 会话新增学科和范围版本；消息增加来源与选定范围，完整重试返回同一已保存依据。
- 成绩趋势/排名比较采用选择的考试；选定学科后用该学科结果和证据，不用新考试总分替代旧考试范围。
- 每条回答反馈可重复提交去重并回读；校验错误不再回显上传内容/输入凭据。
- 原件附件分清报告与试卷用途，不能用试卷权限绕开报告权益。

所有新业务修改分布在 `app/services/`、新 `education` API、领域模型、前端 `features/education/`，没有复制旧巨型页面或恢复备份覆盖现有工程。工作区原有修改保留；未执行 git reset/checkout/清库/部署。

## 6. 部署和剩余边界

新迁移与本地依赖已准备，**没有代为改动业务数据库、重启业务服务或切换旧系统写主**。正式使用前按学校部署流程应用迁移、安装依赖、运行任务 Worker，并配置现有统一身份/账号及经审批的任教关系。迁移遇到重复账号绑定或跨归属数据会拒绝，不自动清洗或删除。

本次未验证/未完成：真实旧数据接入与实体级对账、生产附件存储与容量、真实模型内容质量、市级压测/灾备、学校业务签认；路线图中的完整字典导入、AI 自动结构化拆题、覆盖发布、RAG、家长身份消费、配置评测台、推荐/推送等不据此次测试判定为完成。

普通课程知识、生成式批阅与监护授权不扩大开放；没有通过无来源/无权限的模型回答弥补缺数据。

收尾时已关闭本轮临时 API/Web 进程，并停止新建的 `qa-education-20260918` QA 容器；合成数据库保留供复验，没有删除容器或接触其他业务容器。再次运行浏览器验收前需启动该 QA 容器。

详细运行/字段/权限说明见：[数据契约与运行说明](新旧系统对齐_数据契约与运行说明_2026-09-18.md)。设计规范见：[设计基线](../03-产品与方案/设计基线_2026-09-18.md)。新增第三方组件许可与 OCR 模型来源见：[依赖登记](education_alignment_2026-09-18.md)。
