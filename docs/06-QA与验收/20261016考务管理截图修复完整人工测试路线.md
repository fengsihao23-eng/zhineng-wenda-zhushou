# 考务管理截图修复：完整人工测试路线

日期：2026 年 10 月 16 日。

本轮修改已部署到服务器。线上只读核对时，当前学校学年为 `2029-2030`，有 315 名可选参试学生、73 名有效教师；可以从现有档案中选择测试对象。

## 1. 入口、账号和测试数据

- 登录页：[http://43.161.195.51/login](http://43.161.195.51/login)。
- 考务管理：[直接进入考试列表](http://43.161.195.51/admin/school?tab=exam-management)。
- 侧边栏统一使用“师生班级与考试”，进入后选择上方“考务管理”标签；侧边栏没有单独的考务入口。考试页面与弹窗使用系统的紫色主题。
- 使用具有考务写权限的运营管理员、学校管理员或考试管理员。考试管理员可以操作考务；准备师生档案需使用有档案写权限的管理员。
- 更新发布后先强制刷新浏览器：Windows 用 `Ctrl+F5`，macOS 用 `Command+Shift+R`。未登录时先登录，再打开上面的直达链接。
- 新建专用测试考试，例如 `验收_截图修复_20261016_01`，记下系统生成的考试ID。

准备本校、同一学年、状态为“正常”的三名学生，以及可以登录的教师和学生账号：

| 代号 | 所属班级 | 用途 |
| --- | --- | --- |
| 学生甲 | A 班 | 测试开放、关闭、跨科目和总分 |
| 学生乙 | A 班 | 检查同班学生按学生ID独立授权 |
| 学生丙 | B 班 | 检查班级范围隔离和未授权状态 |
| 学生丁，可选 | A 或 B 班，最初不选入考试 | 检查新增参试学生不会自动获得原授权 |

这里的 A、B 必须使用页面中真实存在的年级、班级。优先使用已有专用测试档案。

如没有可选学生：进入“学生档案 → 导入学生”，下载现行模板，填写唯一账号、姓名、状态“正常”及年级班级，完成预校验和确认入库。学生导入会按学校当前学年建档，创建考试时选择相同学年。**学年以当前页面为准，不要照抄历史验收报告中的学年或人数。**

如需新建测试教师：在“教师档案”下载现行模板；教师账号必须是本校未使用的完整 11 位手机号，状态填“正常”。角色字段按模板格式填写，例如任课 `语文:10.1`、班主任 `10.1`、教研组长 `10.语文`、年级长 `10`，其中 `10` 表示高中一年级，班号要换成测试班真实班号。校级职务使用相应“是否……”列。首次登录新导入账号时，按提示完成修改密码。

## 2. 先检查入口删减

1. 打开考务管理。
2. 检查上方只保留“学生档案”“教师档案”“考务管理”三个标签；仅考试管理员账号只显示考务管理。
3. 确认“班级”“教师任教”“学科”“考试科目”四个入口已消失。
4. 依次打开旧地址，把链接中的 `tab` 改为 `classes`、`teaching`、`subjects`、`exams`。

**通过标准：**旧地址回到有效标签，不再显示原四个页面，也不应出现空白页或报错。

## 3. 创建一场三人、两科的考试

1. 点“＋ 创建考试”，填写测试名称、可选学年和有效日期。
2. 保留“语文”“数学”两科，满分均填 150，删除其余默认科目。
3. 确认基本信息下方不再显示“学校固定为……”这句话。
4. 点“校验并下一步”，选择 A、B 所在年级和班级。
5. 进入“参试学生”，分别在语文、数学中只保留学生甲、乙、丙。
6. 点“下一步：预览”，检查两科均为 3 人，考试去重总人数为 3。
7. 勾选核对确认框，点“确认创建”，记下考试ID。

**通过标准：**创建成功、进入成绩导入；此时考试查询未开放。下载参试名单是可选核对动作。

## 4. 修改考试名称、学年、日期

先检查当前学年内的修改：

1. 返回考试列表，该行点“调整考试范围”。
2. 把名称加上 `_已修改`，把日期改为另一个有效日期。
3. 检查名称、学年、日期三个控件均可操作。
4. 保持原学年，继续到“差异预览”，核对“基本信息变更”中的调整前后值。
5. 勾选确认框，点“确认保存调整”。关闭窗口，再点“查看配置”或重新进入调整窗口。

**通过标准：**列表和重新打开的配置保留新名称、新日期；考试ID不变。

更换学年建议另建一场测试考试：

1. 确保系统已有第二个学年，且该学年存在可选的正常学生。
2. 在调整窗口选择该学年，按提示重新选择年级、班级、学生。
3. 核对预览后保存，再检查列表学年、配置学年和名单年级班级。

**通过标准：**均使用新学年归属；不能把缺少该学年资料的旧学生直接带入新学年。没有第二个可用学年时，记录此项待补数据，不通过办理真实学生升学来凑测试条件。

## 5. 导入语文成绩，先保留数学未导入

1. 在测试考试点“导入成绩”，选择语文，下载成绩模板。
2. 保留模板内的身份列、表头和三人完整名单，只填写“分数”：甲 90、乙 100、丙 110。
3. 上传并点“校验文件”。应显示完整名单校验通过、3 人，尚未写入成绩。
4. 点“确认导入”，再到“查看已导入成绩”下载原文件核对。
5. 暂时不要导入数学，用于检查未导入科目不可开放成绩。

**通过标准：**语文显示已导入，数学显示未导入；仅导入成绩后，教师、学生仍不能查询这场考试。

## 6. 检查教师筛选位置、角色默认值和说明入口

入口：该考试 →“成绩开放设置 → 1. 教师查询控制”。

1. 确认顶部原“由运营管理员按教师逐人配置……”说明段落已删除。
2. 搜索框、年级、班级、学科、职务及“勾选筛选结果”应在教师列表上方横向区域。
3. 分别操作筛选项；选择年级后，班级选项应跟随该年级变化。班级只匹配实际任课或班主任班级，教研组长、校级查看范围不会让非任课教师误命中；同时选择年级、班级、学科时，必须匹配同一条档案职责。
4. 点右侧编辑区上方“下载默认选项规则（Excel）”，应直接下载 `教师默认选项规则.xlsx`，内含“默认选项规则”“使用说明”两张表；页面不再展开规则表格。
5. 依次勾选不同角色的教师，逐人对照下表。仅检查时可以取消勾选，不必保存。

| 左侧教师角色 | 右侧默认成绩类型 | 默认科目及学生范围 |
| --- | --- | --- |
| 任课教师 | 个人单科、班级单科 | 任教学科、任教班级 |
| 班主任 | 个人单科、班级单科、班级综合 | 本次全部科目、负责班级 |
| 教研组长 | 个人单科、班级单科、年级单科 | 负责学科、负责年级 |
| 年级长 | 上述个人、班级、年级类型，包括班级综合和年级综合 | 本次全部科目、负责年级 |
| 教务主任、校长、总务主任、全校数据查看 | 六类全部，包括全校综合 | 本次全部科目、全部参试学生 |
| 兼任多个角色 | 各角色类型、科目、范围的并集 | 对照该教师的各项职责逐一核对 |

还要检查：

- 成绩科目仅默认选中已导入且符合角色的科目；数学此时标记未导入且不可勾选为成绩查询。
- 诊断报告使用对应类型，本次已配置的数学可出现在诊断科目中；这不代表已有数学成绩或报告文件。
- 作文报告默认不选。
- 班主任兼任任课教师时，应包含“班级综合成绩”和“班级综合诊断”。
- 把“成绩数据”或“诊断报告”总开关关掉再打开，仍按当前教师角色恢复默认选项。
- 选择已有授权教师时优先显示上次保存内容；不要把保留原配置误判为角色规则未更新。
- 如果职责没有匹配本次科目或参试班级，应提示补选，不应默认放开全部学生。
- 改变筛选后，不符合条件的教师应退出当前编辑和勾选范围；其未保存草稿保留，重新筛选并勾选后可继续编辑。

## 7. 教师直接保存，全程不下载预览

1. 选择一名负责 A 班的语文教师。
2. 保留“个人单科成绩”“班级单科成绩”，成绩科目选语文；学生范围按班级，仅选 A 班。
3. 为方便对照实际成绩，可暂时关闭诊断和作文报告。
4. **不要点“下载授权预览”，直接点“确认保存生效”。**
5. 关闭窗口、刷新页面，再选该教师，确认类型、科目、A 班均已保留。
6. 改动一个有效选项后，保存按钮应仍可直接使用；再次保存并重新打开核对。

**通过标准：**没有下载记录也能保存成功。类型或学生范围不完整时应阻止保存；不能把正常的完整性校验误判为下载依赖。

多选教师时额外检查：选择一位配置完整的教师和一位缺少内容或范围的教师，下载、保存按钮均应可点击；点击后应明确提示缺项教师姓名、教师ID和缺失内容，并定位首位待补全教师。补齐全部所选教师的类型、科目、范围后，两项操作应成功。可用批量设置按钮统一应用当前范围或类型科目，系统不自动扩大任何人的范围。

## 8. 学生直接保存，全程不下载预览

1. 切换“2. 学生查询控制”。
2. 选择“开放查询”，操作科目选语文，学生只选甲、乙。
3. **不要下载授权预览，直接点“确认保存生效”。**
4. 重新打开，检查当前查询范围：甲、乙已开放语文，丙仍未授权。
5. 确认数学仍不可作为已导入成绩科目开放。

**通过标准：**学生授权也独立于下载；甲、乙、丙的权限分别保存。

## 9. 换教师、学生账号验证真实查询结果

保留管理员窗口，另开无痕窗口分别登录，避免混用账号。

1. **教师账号：**进入“考试成绩与报告”，选择本次考试，应只看到 A 班甲、乙的语文成绩，不能看到 B 班丙的成绩和数学成绩。
2. **学生甲账号：**进入“考试成绩与报告”，应只看到本人的语文 90 分，不能看到乙、丙或数学。
3. **学生丙账号：**本次考试尚未给丙开放，不应看到本次考试成绩。
4. 切回管理员，按第 5 节同样方法导入数学：甲 70、乙 80、丙 90。
5. 数学导入后先刷新教师和学生页面，检查原授权没有自动增加数学。
6. 管理员仅为学生甲开放数学，直接保存。
7. 学生甲刷新，应能看到语文 90、数学 70；全部本人参试科目开放后，才显示完整总分 160。

**通过标准：**以管理员明确保存的“人、科目、范围”为准；导入文件不等于自动开放查询。

## 10. 可选下载、上传仍能使用

1. 回到授权窗口，选好一份有效配置，下载授权预览 Excel，检查考试ID、教师或学生ID、科目与范围。
2. 下载后再改一个有效选项，仍可直接确认保存，无须重新下载。
3. 如需测上传：用本次下载的文件，保持表头、考试ID和人员ID正确，按列内已有格式修改后上传。
4. 上传应只载入待保存配置。核对后直接“确认保存生效”，无须再次下载。

**通过标准：**下载、上传和保存都可正常使用；上传载入不等于已经生效。

## 11. 关闭、撤销、日志和只读账号

1. 在学生查询控制中选甲、语文，改为“关闭查询”，直接保存。
2. 学生甲刷新，应只剩已开放的数学；完整总分应不再显示。
3. 在教师列表撤销测试教师授权；教师刷新后不应继续读取本次授权数据。
4. 回到考试列表点“操作记录”，切换“考试操作”“成绩开放设置”，核对考试ID、调整前后内容、对象、操作人和时间。
5. 如有学校只读账号，用它打开考务管理，应能查看已有内容和记录，但不能创建考试、导入、调整或保存授权。

## 12. 补充边界测试

| 测试 | 操作 | 预期 |
| --- | --- | --- |
| 取消修改 | 修改名称或勾选授权后取消，不点保存 | 重新打开仍是原保存值 |
| 名称或科目错误 | 名称留空、科目重名、满分为 0 | 明确提示，不能保存 |
| 不完整成绩文件 | 在副本中删掉一名参试学生后校验 | 提示缺少人数，不能部分导入 |
| 非法分数 | 在副本中填负数或超过 150 的分数 | 校验失败，没有部分成绩写入 |
| 两窗口同时修改 | A、B 窗口打开同一考试，A 先保存；B 用旧版本提交 | B 提示资料已更新；刷新后核对再保存 |
| 新增参试学生 | 已授权后，在调整范围中把丁加入考试并保存 | 已有成绩、报告保留，丁不自动加入原授权 |
| 删除后重导 | 在测试考试删除某科成绩文件，再按新完整名单重导 | 原该科成绩权限被清除；重导后须重新授权 |

完成后记录：考试ID、账号角色、测试步骤、预期、实际结果和截图。可撤销测试教师、学生查询授权；系统目前没有整场考试删除入口。
