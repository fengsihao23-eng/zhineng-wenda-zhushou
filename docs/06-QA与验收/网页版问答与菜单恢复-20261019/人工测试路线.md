# 网页版问答与菜单恢复：个人测试路线

## 本次调整

- 学校管理员侧栏保留「教师档案、学生档案、考务管理、报告管理」，补回「提示词及人工」。超级管理员的同名入口只出现一次；其他角色仍按原权限显示。
- 网页版智能问答恢复原来的桌面布局：左侧导航、居中问候语、宽输入框和紫色主题，回答继续支持 Markdown 和数学公式。
- 当前问答、提示词与回答限制、考试授权、会话、来源、报告及人工留言使用原有接口和数据，没有回退后端逻辑。
- 已合入另一窗口最新的考试科目选项和作文报告筛选修复。

## 你可以这样验收

1. **刷新页面**：Windows 用 Ctrl+F5，Mac 用 ⌘+Shift+R。
2. **管理员菜单**：登录后检查左侧五项入口，点「提示词及人工」，依次打开「提示词与回答限制、人工留言、操作记录」。每次只有当前菜单高亮。
3. **网页版问答**：学生进入 `/chat`，教师进入 `/teacher/chat`，也可直接点击左侧「智能问答」或「智能问答与留言」。应看到原来的桌面布局，没有手机外框和小程序底部导航。
4. **问答与历史**：直接输入问题、继续追问；检查分数、来源和既有会话。提问完成后「新会话」应可用；网络失败时问题保留，重试不会重复提交。
5. **报告与留言**：从顶部「学习工具」进入报告中心或历史会话；从「人工留言」提交问题、查看回复、追加和确认结束。报告预览、下载和权限限制沿用原规则。
6. **原有修复**：在考务管理核对教师/学生授权保存、失败重试、取消授权确认；在考试和作文报告页检查另一窗口修正的科目选项。
