# 考务管理 v17：验收与人工测试路线

日期：2026 年 10 月 16 日。

## 改动范围

按用户提供的《考务管理_高保真原型.html》v17、《业务流程图_V1.html》r84，以及截图圈出的“②考务管理”两个子流程实现：

- 创建考试：基本信息与科目 → 年级与班级 → 分科参试学生 → 预览与确认。
- 考试成绩开放设置：由运营管理员分别配置教师查询权限、学生本人查询权限。
- 成绩 Excel：完整名单模板、预校验、确认导入、小题明细、原文件下载、删除后重导。
- 后续调整：差异预览、关联数据提示、历史学年班级快照、权限不自动扩大。
- 操作记录：考试ID、对象、科目与范围、前后配置、操作人和时间。

“学生查询控制”指运营管理员为学生配置查询权限，**不是学生自行操作**。学生与教师均不能操作开放设置。学生开放粒度按 v17 原型的最终交互实现为按科目开放或关闭；r84 流程图中的“按整次考试”表述与原型存在差异。

文件版本、实现口径及考务流程原文摘录见 [需求基线目录](../04-业务流程图/考务管理-v17-20261016/)。历史来源考试保留原“考试科目”入口及原访问规则；本次新流程创建的考试在“考务管理”中维护。

## 最短人工测试路线

### 1. 登录并进入考务管理

打开 [服务器登录页](http://43.161.195.51/login)，使用运营管理员账号登录。

入口：**业务生产 → 考务管理**，或 **师生班级与考试 → 考务管理** 标签。

直达：[考务管理](http://43.161.195.51/admin/school?tab=exam-management)。已有页面请刷新以加载本次版本。

准备两名以上状态为“正常”、有本次考试学年班级记录的测试学生，并记下学生ID；准备一名可登录的教师。没有学生时，先从“学生档案”导入或完成目标学年建档。

### 2. 创建一场测试考试

1. 点“＋ 创建考试”，名称填写 `验收_考务_20261016`，选择系统已有学年和有效考试日期。
2. 保留语文、数学两科，满分均设为 150，删除其他默认科目。
3. 点“校验并下一步”，勾选年级、班级，再点“下一步：选择参试学生”。
4. 分别切换语文、数学标签，检查按班级全选、展开名单、按学生ID勾选。让两科名单有一人差异，确认各科人数独立计算。
5. 点“下一步：预览”，检查科目满分、各班各科人数、去重后的考试总人数；下载参试名单 Excel。
6. 勾选“我已核对……”，点“确认创建”。应生成唯一考试ID，并进入成绩导入；列表成绩开放状态为“未开放”。

### 3. 导入成绩

1. 选择语文，点“下载成绩模板（Excel）”。核对已经预填本次该科完整参试名单。
2. 只填写“分数”列，例如 90、95，其余身份列保持不动。保存后选择文件并点“校验文件”。
3. 应提示“完整名单校验通过：N 人。尚未写入成绩”；点“确认导入”。
4. 在“查看已导入成绩”中点“下载查看”，确认得到刚上传的原文件。
5. 按同样路线导入数学。如果要测小题，在“主观分”之后添加 `1`、`2` 等题号列并填得分，题号和题数以表头为准。

**检查点：导入成功不等于开放查询。此时教师、学生都不应看到这场新考试的成绩。**

### 4. 运营管理员开放教师查询

入口：考试列表该行 → **成绩开放设置 → 1. 教师查询控制**。

1. 按姓名、教师ID或账号找到教师并勾选。
2. 选择“成绩数据”的查询类型与已导入的科目；按需配置诊断报告类型、科目和语文/英语个人作文报告。
3. 选择“全部参试学生”“按年级”或“按班级”。多选教师时可分别编辑，也可使用页面上的批量设置按钮。
4. 点“下载授权预览（Excel）”，核对教师ID、类型、科目与学生范围，再点“确认保存生效”。
5. 修改任何配置后，保存按钮应重新禁用，须重新下载最新预览。

### 5. 运营管理员开放学生查询

入口：同一考试 → **成绩开放设置 → 2. 学生查询控制**。

1. 选择“开放查询”，勾选语文、选择一名参试学生。
2. 下载授权预览，核对变更前后范围，再点“确认保存生效”。
3. 数学先不开放，用于检查科目隔离。未导入成绩的科目不能勾选为开放。

### 6. 切换账号检查实际权限

建议使用另一个浏览器窗口或退出后重新登录，避免账号混淆。

- **教师账号：**进入“考试成绩与报告”，选择该考试和获准的查询类型，只能查看管理员保存的科目与学生范围。该页没有开放设置操作。
- **学生账号：**进入“考试成绩与报告”，应只看到自己的语文成绩、已有小题与获准的报告，看不到数学及其他学生的成绩。
- 管理员再为该学生开放数学。学生刷新后应看到数学；全部参试科目都已开放时才展示完整考试总分及其排名。
- 若尚未上传报告，显示暂无报告；不得用摘要或临时生成文件冒充已上传 PDF 原件。

### 7. 关闭、撤销与操作记录

1. 管理员回到“学生查询控制”，选该学生、选语文、改为“关闭查询”，下载预览并保存。学生刷新后语文应消失，其他已开放科目保留。
2. 在“教师查询控制”点对应教师的“撤销”。教师刷新后不再能读取该次授权数据。
3. 回到考试列表点“操作记录”，分别检查“考试操作”“成绩开放设置”，核对考试ID、对象、范围、操作人和时间。

## 需要补测的边界路线

| 测试 | 操作 | 预期 |
| --- | --- | --- |
| 取消创建 | 填写、选择或预览后取消 | 不生成考试和参试记录 |
| 基础信息错误 | 留空名称、科目重名、满分 0 或负数 | 拦截并提示，不能继续保存 |
| 同名考试 | 再填同学年同名考试 | 保存前提示已有考试ID，确认后新考试ID不同 |
| 同名学生 | 选择同班同名但学生ID不同的两人 | 可分别选择，按学生ID去重 |
| 不完整名单 | 删除成绩文件中的一名参试学生 | 提示缺少人数，不可确认导入，无部分成绩写入 |
| 错误成绩 | 填负数、超满分、改学生ID/姓名、重复学生、重复题号或公式 | 校验失败，禁止确认 |
| 重复上传 | 已导入同科成绩后再次上传 | 要求先删除已导入文件 |
| 调整范围 | “调整考试范围”增加学生或科目 → 差异预览 → 确认 | 已有成绩、报告保留；已有权限不会自动覆盖新增数据 |
| 历史归属 | 创建后让学生换班，再查看考试配置 | 仍显示考试创建时保存的年级、班级 |
| 删除重导 | “查看已导入成绩”→ 删除成绩文件 → 确认删除 → 重导 | 该科成绩、小题及成绩查询授权清除；原报告保留；重导后须重新开放 |
| 只读账号 | 用学校只读账号进入考务管理 | 可查看配置、原文件和记录，没有创建、导入、调整或授权按钮 |
