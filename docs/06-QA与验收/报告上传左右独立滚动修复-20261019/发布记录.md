# 报告上传左右独立滚动修复

## 修改

- 上传报告第二步“预览并调整归属”中，左侧文件列表与右侧归属配置分别滚动，滚到边界也不会带动另一侧或外层抽屉。
- 标题、步骤、批次摘要和底部“上一步／下一步”按钮保持可见。
- 切换文件保留左侧列表位置，右侧回到新文件的配置顶部。
- 窄屏使用上方横向文件列表、下方纵向归属配置，两块分别滚动。
