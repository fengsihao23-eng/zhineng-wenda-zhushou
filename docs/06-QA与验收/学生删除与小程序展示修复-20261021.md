# 学生误导入删除与小程序展示修复 · 2026-10-21

## 修复内容

1. 学生误导入删除：旧清理规则只识别直接关联学生ID的个人数据，把通过学校、账号关联的智能问答会话、留言、试问、操作记录、每日额度和在线状态误判为共享业务。现将这六类账号个人数据加入清理范围，影响预览显示中文名称和条数。确认后在同一事务内清理，真实共享文件的归属检查仍然生效。
2. 小程序问答：数据来源默认收起，点击“展开”显示原成绩与报告入口，再次点击收起。前台同步保留当前选择，重新打开历史会话时恢复收起；展开后的来源继续向后台检查权限。
3. 小程序报告：报告列表、预览页底部和查看下载记录不显示内部版本号。报告访问保留后台版本校验，翻页、PDF下载与撤权处理继续使用原链路。

此前被误判拦截的办理任务，重新打开会按新规则计算影响范围。身份核验和误导入核实尚未保存时，页面会明确提示完成这两项并点击“保存核验，继续预览”，随后勾选影响范围确认再删除。任务审核、原值校验、二次确认、学校隔离及重复提交保护继续参与确认。
