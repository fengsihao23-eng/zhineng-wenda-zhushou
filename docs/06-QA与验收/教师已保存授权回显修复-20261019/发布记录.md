# 教师已保存授权回显修复

## 修改

- 打开“成绩开放设置”时，等待教师信息读取完成，自动勾选已有授权的教师，并展示第一位教师的已保存配置。
- 回显已保存的成绩类型、成绩科目、诊断类型、诊断科目、作文语种及学生范围。仅在点击“重新按档案预选”时使用教师档案建议。
- 教师列表显示“可查看并调整已保存权限”，摘要同时显示已保存授权人数及本次已选人数。
- 保存、刷新重开以及切换教师／学生查询控制后保持已保存配置；取消授权后同步更新已保存人数、勾选状态和当前编辑教师。
- 打开窗口或取消勾选不写入授权；筛选及后台读取保留当前编辑草稿。

## 验证

- 前端 lint、TypeScript 及生产构建通过，31 项单元测试通过。
- 使用隔离 PostgreSQL、真实 API 和生产前端运行 19 项 Playwright 回归，全部通过。
- 覆盖已保存配置自动回显、修改保存、刷新重开、页签切换、取消授权、失败重试和并发冲突。
- 发布使用 ubuntu 账号及 sudo -n，仅重建 web。部署脚本保留数据库备份及旧镜像，校验考试配置和授权数据内容。

验证结果见 [validation.json](validation.json)。部署及线上核对结果将在发布后补充。
