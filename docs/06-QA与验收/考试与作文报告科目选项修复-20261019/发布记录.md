# 考试与作文报告科目选项修复

## 修改

1. 教师成绩开放设置展示语文、数学、英语、物理、化学、生物，以及本次考试的其他科目。未配置的科目标注“本次考试未配置”；已配置但未导入成绩的科目标注“未导入”。已配置的诊断科目可选择，不依赖成绩导入。
2. 增加本次已配置科目及操作说明：其他科目先在“调整考试范围”添加科目和参试学生，成绩科目还需导入成绩。
3. 作文批改报告列表的科目筛选固定为“全部科目、语文、英语”。切换报告分类清除不适用的科目，重置筛选后仍保持两个语种。
