# 0922 教师变更、学生新增与登录修订验收

本次仅修改用户指定的「教师信息变更（删旧 → 重导）」「学生批量导入（新增）」及登录账号自动识别。依据根目录 `0922业务流程图_教师信息变更（删旧 → 重导）_V1.html` 第 2、3 页签，兼容随后提供的 `阳江一中高中一年级学生资料模板0511.xls`。流程图、原始学生文件、教师新增的业务规则及其他模块保持原样。

## 交付行为

- 教师删除不受任教关联拦截；账号名释放，原登录失效，历史用户关联、任教记录和成绩保留。
- 删除时保存原 24 列资料快照、删除人及时间，支持按姓名 / 原账号查询；重导后快照仍可查看。
- 同账号重导自动匹配原记录；更换账号时可在预览指定原教师删除记录。已改密码原样保留；仍使用初始密码时，密码随新账号生成并继续强制首登改密。
- 每条删除记录只能用于一次重导；并发消费、跨校引用、重复关联和事务中途失败均有保护。
- 学生 `.xls`、`.xlsx` 共用固定 30 列校验、全批确认、错误清单和已注册家长手机号绑定。学号可留空，学生手机号不代替家长手机号。
- 学生密码哈希计算最多并行 8 路，保持 bcrypt 强度和全批事务。
- 登录页只保留用户名和密码；服务端根据有效凭据确定身份与学校。仅在账号及密码均相同的多身份情况下，验证后显示具体身份卡片；错误密码不返回身份列表。
