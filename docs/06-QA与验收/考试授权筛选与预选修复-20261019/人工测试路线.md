# 考试成绩开放设置：个人测试路线

## 入口与准备

1. 用学校运营管理员账号打开 [考务管理](http://43.161.195.51/admin/school?tab=exam-management)。若仍是旧页面，先强制刷新：Mac 按 `Command + Shift + R`，Windows 按 `Ctrl + F5`。
2. 找到需要检查的考试，点击 **成绩开放设置 → 1. 教师查询控制**。截图中的考试是“高一数学大练习（六）”，考试ID为 `EX-20261019-3DF181B0`。
3. **筛选、勾选、重新预选、下载预览均不生效；只有“确认保存生效”才写入授权。** 如要实际保存，建议另建名称带“授权复测”的考试，导入测试成绩；不要随意改动正式考试已有授权。
4. 先在教师档案中找两名职责不同的教师，记下姓名、教师ID、账号、任教学科、年级班级及兼任职务。下面称为教师A、教师B。

## 路线一：复测截图问题（约5分钟，不必保存）

### 1. 下拉选项是否齐全

- 查看顶部“年级、班级、学科”。选项应来自本校有效教师的档案职责，而不是只来自本次考试。
- 截图对应学校的只读数据核对结果：教师职责覆盖**高一、高二、高三，48个年级班级组合、14门学科**；本次数学考试仅有6个参试班。顶栏应能筛选考试之外的教师职责。
- 选择“高中二年级”，班级选项应只列高二教师实际负责的班级，且按班号自然排序；改选年级时，原班级筛选应清空。
- 点击“重置筛选”，搜索、年级、班级、学科、职务全部恢复，但已经勾选的教师及草稿不丢失。

### 2. 组合筛选是否真的对应同一条职责

- 按教师A档案中的同一条“年级＋班级＋学科＋职务”筛选，应能找到教师A。
- 反例：某教师任教“高二1班物理”、另一项职责是“高一某班班主任”，筛选“高一＋物理”不能把两条职责拼起来当作命中。
- 再加“班主任”职务时，只能匹配班主任这条职责上的年级、班级，不能借任课职责命中另一个班。
- 无匹配时应明确显示空结果，而不是回退为全部教师；“勾选筛选结果”此时禁用。

### 3. 选人后，身份、默认科目、学生是否对应

- 勾选教师A，右侧**当前编辑的姓名、教师ID、账号**须与左侧一致；已选教师标签同时展示ID，避免同名误认。
- 未授权教师首次选中时，来源为“教师档案默认建议”；已有授权时优先载入“已保存的授权”，不会自动替换为新建议。
- 任课默认建议仅匹配“该教师的科目＋对应参试班级”，班主任、年级长等也只有职责与本次考试确实匹配才参与预选；有效兼任职责取并集。
- 成绩科目只可选已导入科目；诊断科目限本次考试已配置科目。无匹配不能自动换成其他科目或其他班。
- **截图中的高二物理教师，对高一数学考试没有职责交集，因此不自动预选数学或高一学生，这是正确的安全行为。** 若确需额外授权，管理员可手动配置，但须核对范围后保存。
- 成绩类型、成绩科目、报告类型、报告科目始终可见，不再因为未勾选总开关而找不到具体选项。
- 没有配置英语的考试，“英语作文”应标为“本次考试未配置”并禁用；“全选作文报告语种”仅选择当前可用语种。
- 向下滚动到“当前教师授权预览”，核对姓名、ID、科目与覆盖人数；展开“查看范围内的参试学生与科目人数”，核对学生ID、姓名、考试年级班级以及各科人数。

## 路线二：多人草稿与保存（约5～10分钟，使用测试考试）

1. 选教师A，修改一个诊断类型或学生班级；再选教师B，给B不同的配置。来回点击已选教师标签，A、B各自的科目、班级、类型必须独立，不能串人。
2. 修改搜索或年级班级筛选，让A暂时不在左侧列表。顶部应显示“其中X位不在当前筛选内”；A的标签、身份和草稿仍保留。**保存作用于全部已选教师，包括筛选外的已选教师。**
3. “勾选筛选结果”只追加当前结果，不覆盖已选教师的手动草稿；“取消勾选筛选结果”只取消当前结果；“清空已选教师”取消本次全部选择。这些操作都不会撤销已生效授权。
4. 分别让一位教师缺少查询内容、科目或年级班级，点击“确认保存生效”：应说明哪位教师缺少什么，定位到该教师，不显示保存成功。
5. 如果某科目的参试名单不包含当前所选范围的任何学生，应提示“某科在当前学生范围内没有参试学生”，不能保存一份看似成功但实际没有对应数据的授权。
6. 补全后，核对右下角本次保存人数，直接点击“确认保存生效”，**无需先下载Excel**。应显示成功，教师选择、当前编辑、筛选与表单仍保留。
7. 关闭窗口、刷新页面、再次进入并选择A、B；来源应为“已保存的授权”，逐人核对与刚才保存一致。
8. 点击“重新按档案预选”，只重置**当前教师**为最新档案建议，不改另一人的草稿，也不直接修改已有授权；如只是检查，关闭窗口即可，不要保存。

## 路线三：Excel与批量设置（可选）

- 下载授权预览，逐行核对考试ID、教师ID、姓名、类型、科目、学生范围；重新上传后应载入对应教师草稿，尚未生效。
- 故意改错一行姓名但保留原人员ID，上传须提示“姓名与人员ID不匹配”，不得默默载入另一个人的授权；学生授权表适用相同校验。
- 选中两名职责不同的教师，点击“各人按档案重新预选”：每人按自己的档案生成建议，不能把A的科目或班级复制给B。
- 只有明确点击“应用当前学生范围”或“应用当前类型和科目”才会复制当前人的相应配置；按钮说明会提醒作用于全部已选教师。
- “各人默认班级”来自各人职责与本次考试的匹配范围，不等同于全校所有班级。

## 路线四：实际查询与撤销（建议最后验证）

1. 管理员保存测试授权后，用教师A账号登录“考试成绩与报告”，只应看到已授权考试、科目、学生与类型；教师B应按B的配置展示，不能因同职务共享A权限。
2. 回管理员窗口，对A点“取消授权”：先弹出对象与影响确认；“保留授权”不改变数据；确认取消后A不能继续查询该次授权数据，B不受影响。
3. 切到“2. 学生查询控制”，为测试学生按已导入科目开放本人查询；学生账号只能查本人，不能查同班其他学生。
4. 回“操作记录 → 成绩开放设置”，检查本次授权、学生开放及撤销的教师/学生ID、范围、操作人和时间。

## 如何判断通过

- 筛选选择来自真实教师档案，组合条件不会跨职责拼接。
- 右侧身份、默认建议、手动草稿、预览与保存后回显始终对应同一教师ID。
- 不匹配不猜测、不自动扩大范围；不完整或没有对应学生的数据配置不能保存。
- 既有正式授权不会因本次发布、修改筛选或重新预选而自动改变。
