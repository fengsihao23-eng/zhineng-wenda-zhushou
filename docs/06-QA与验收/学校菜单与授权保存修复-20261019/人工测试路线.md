# 学校菜单与考试授权保存修复：人工测试路线

适用版本：GitHub 分支 `codex/school-menu-permissions-fix`。本路线对应本次四张截图反馈。

## 一、进入新版页面，核对四个菜单

1. 打开 http://43.161.195.51/login ，使用学校管理员账号登录。已有登录页面先强制刷新：Windows 按 `Ctrl + F5`，macOS 按 `Command + Shift + R`。
2. 登录后应进入“考务管理”。左侧从上到下只有“教师档案、学生档案、考务管理、报告管理”四个模块入口。
3. 依次点击四个入口，确认页面标题与菜单名称对应，每次仅当前菜单高亮。
4. 在教师档案和学生档案中确认能看到对应信息列表；在考务管理中看到考试列表；在报告管理中看到报告维护页面。
5. 再点“教师档案 → 学生档案”，按浏览器后退，应该回到教师档案，菜单高亮随之切换。刷新后仍停留在当前模块。

直达地址：

| 模块 | 地址 |
| --- | --- |
| 教师档案 | http://43.161.195.51/admin/school?tab=teachers |
| 学生档案 | http://43.161.195.51/admin/school?tab=students |
| 考务管理 | http://43.161.195.51/admin/school?tab=exam-management |
| 报告管理 | http://43.161.195.51/admin/reports |

权限说明：以上四项以学校管理员为准。学校只读账号没有报告管理入口；仅有考试管理员权限的账号只显示考务管理。菜单调整不扩大账号原有的接口权限。

## 二、复测图三、图四：教师保存后保留编辑区

建议使用专门的测试考试、测试教师和测试学生。本路线中的“保存”和“取消授权”会实际修改所选考试的查询权限。

路线：左侧“考务管理 → 选择一场已导入成绩的考试 → 成绩开放设置 → 1. 教师查询控制”。

1. 先按年级、班级筛选，再搜索一位测试教师并勾选。
2. 核对右侧“当前编辑”的教师姓名和教师ID。选择要开放的成绩类型、已导入的成绩科目，以及相应的学生范围；不需要的诊断或作文权限可取消勾选。
3. 直接点击“确认保存生效”，无须先下载授权预览。
4. 请求期间，按钮显示“正在处理…”，配置控件暂时不可操作，避免重复提交。
5. 成功后，应自动显示绿色提示“保存成功，已更新 1 位教师的查询权限。”。当前教师仍被勾选，右侧编辑内容、年级、班级和搜索条件保留，不应回到“请选择需配置权限的教师”。
6. 修改一项需要开放的内容，再保存一次，确认仍然成功，且保留当前编辑状态。
7. 关闭弹窗、刷新页面，再打开同一场考试的成绩开放设置，重新选择该教师，核对已保存的选项。
8. 使用该测试教师账号进入“考试成绩与报告”，确认能查询刚开放的考试与对应数据。

多教师补测：同时勾选两位测试教师，分别设置完整内容，再保存。应显示“已更新 2 位教师”，保留两人的勾选和当前正在编辑的教师。

## 三、验证保存失败有明确提示

在同一教师编辑区：

1. 将学生范围改为“按年级”，清空所有授权年级。
2. 点击“确认保存生效”。应提示该教师“未选择授权年级或班级”，并定位到待补全的教师；当前配置保留，不能显示保存成功。
3. 勾选需要的年级，或恢复原先正确的学生范围，再次保存，应成功。

可选网络异常测试：打开浏览器开发者工具，在 Network 面板选择 Offline，再点击保存。应显示“操作未完成”和网络异常原因，保留所选教师和配置。恢复 Online 后可重试。测试时保持原有正确配置即可，无需扩大查询范围。

## 四、复测图二：“取消授权”按钮

旧按钮“撤销”改为“取消授权”，用于关闭该教师对**本次考试**的查询权限。它只对已授权教师显示，因此其他未授权教师旁没有这个按钮。

1. 在“教师查询控制”中，找到显示“已授权”的测试教师，点击旁边“取消授权”。
2. 应出现包含教师姓名的确认说明，明确取消后不能查询本次考试已授权的成绩和报告。
3. 先点击“保留授权”，该教师应继续显示“已授权”。
4. 再次点击“取消授权 → 确认取消授权”，应出现“已取消某某对本次考试的查询授权。”，教师状态变为“未授权”，该行的取消按钮消失。
5. 若同时正在编辑其他教师，其他教师的勾选和配置应保留。
6. 刷新测试教师端的“考试成绩与报告”，确认本次考试不再可查询。需要继续测试时，回到管理员端重新勾选该教师、核对配置并保存，即可重新授权。

## 五、学生授权保存补测

路线：同一考试的“成绩开放设置 → 2. 学生查询控制”。

1. 选择“开放查询”，勾选一门已导入的操作科目。
2. 按年级、班级筛选，选择一至两名测试学生。
3. 点击“确认保存生效”。应显示“保存成功，已开放所选 N 位学生的查询权限（科目）。”。
4. 已选人数、操作科目和年级班级筛选应保留；下方“当前查询范围”更新。
5. 用该测试学生账号打开“考试成绩与报告”，核对已开放的科目。
6. 回到管理员端切换“关闭查询”，保留所选学生和科目，再保存。应出现关闭成功提示；学生端刷新后不能查询已关闭科目。
