# 报告管理：个人验收路线

## 入口与准备

1. 打开 [服务器报告管理](http://43.161.195.51/admin/reports)，使用学校运营管理员账号登录；页面左侧入口为「报告管理」。
2. 准备两份可正常打开的 PDF 副本，优先使用测试考试，避免把测试文件关联正式考试。
3. 在页面顶部点击「考务管理」，检查目标考试已配置科目与参试学生。报告只能选择该次考试对应科目的参试对象，学生年级、班级使用考试保存的归属。
4. 如需验证教师、学生查询，准备对应的教师和学生账号；已有考试授权沿用「考试成绩开放设置」。

单份 PDF 不超过 15 MB、100 页；每批最多 30 份，合计不超过 30 MB。

## 路线一：上传并核对，约 5 分钟

**报告管理 → 报告维护 → 上传报告 → 三步核对 → 保存。**

| 步骤 | 你的操作 | 应看到的结果 |
| --- | --- | --- |
| 选择范围 | 搜索并选择目标考试，选择「诊断报告 → 个人学情诊断」，单选一个科目 | 只显示本次考试有参试名单的科目；科目为单选 |
| 取得文件名 | 点击「下载本次范围命名清单」 | CSV 包含对应学生及建议文件名；同名学生用学生ID或账号区分 |
| 准备文件 | 从清单复制两个建议文件名，给对应 PDF 副本改名；保留 `.pdf` 扩展名 | 文件名格式为 `考试ID_学生ID或账号_姓名_科目_报告类型.pdf`，字段用半角下划线分隔 |
| 校验文件 | 选择或拖入两份 PDF | 分别提示 PDF、命名及参试范围校验通过；显示「校验通过 2 / 2 份」 |
| 核对归属 | 点击「下一步：预览归属」，在左侧逐份选择文件 | 展示自动关联的学生、科目和报告类型；关联学生支持姓名、ID、账号模糊搜索及班级筛选 |
| 预览内容 | 每份点击「预览 PDF」，核对实际内容；多页文件可翻页 | 显示真正的 PDF 页面；关闭预览仍留在上传抽屉；文件标为「已预览」 |
| 保存 | 点击「下一步：核对清单」，核对两份文件后点击「确认保存」 | 抽屉关闭，列表新增两份 v1 报告；刷新页面后仍存在 |

同批可以在第二步逐份修改报告类别、类型及对象，但科目保持第一步所选科目。修改后需要重新预览核对。语文、英语作文批改报告应分别按科目上传。

## 路线二：异常与重复，约 2 分钟

1. 上传有效但命名为 `随便命名.pdf` 的文件：应列出命名问题，不能进入下一步；移除后改名重选。
2. 上传扩展名为 PDF 的损坏文件：应显示 PDF 校验失败。
3. 再次上传路线一已保存报告，或同批重复选择同一归属：核对清单时应列出重复文件及原因，并提示已有报告使用「替换更新」；列表数量不增加。
4. 在任何保存前步骤点击「取消」：列表不产生报告，操作记录不产生成功上传记录。

## 路线三：替换更新，约 3 分钟

**列表筛选目标考试 → 对应行「查看」→ 替换更新。**

1. 查看原 PDF，记下报告ID、对象、科目和当前版本。
2. 选择新的有效 PDF，点击「预览新 PDF」，填写替换原因。
3. 勾选「已核对新 PDF，报告归属保持不变」，确认替换。
4. 应变为 v2；报告ID、考试、类别、科目及对象保持一致。
5. 再次进入「查看」：版本记录有 v2 当前版本和 v1 历史版本；管理员可以预览、下载历史 PDF。
6. 替换前取消，或选择损坏 PDF 时，原版应继续可用。

替换新 PDF 的文件名不要求沿用上传时的命名规则。归属填错时，应重新上传到正确归属，再删除错误报告。

## 路线四：核对教师、学生权限，约 5 分钟

1. 在「考务管理 → 考试成绩开放设置」查看或配置该次考试的教师查询权限、学生查询开放。维护报告本身不会新增授权。
2. 返回「报告管理 → 核对查询权限」，选择相同考试与具体教师账号：应逐份显示「可查询／不可查询」及原因。
3. 教师仅获某班或部分科目授权时，超出其完整授权范围的全校、年级或班级整体报告应不可查询。
4. 切换为「学生」并选择学生账号：只列该学生的个人学情诊断、个人作文批改报告；不列其他学生、班级、年级、全校报告。
5. 分别用对应教师、学生账号登录，在「考试成绩与报告」选择相同考试；报告列表及可打开的 PDF 应与核对结果一致。
6. 替换为 v2 后重新查询：仍使用原查询入口，打开当前新版；查询端不提供历史版本入口。

建议教师、学生使用不同浏览器或无痕窗口，避免管理员账号与查询账号相互覆盖。

## 路线五：删除与操作记录，约 3 分钟

1. 在报告列表勾选刚才用于测试的两份报告，点击「删除所选」。
2. 先检查清单，点击「取消」：两份报告都应保留。
3. 再次删除，填写删除原因并勾选确认，再点击「确认删除」。
4. 两份报告应从列表移除；教师、学生刷新后不能继续从查询入口获取这些报告，也不能回退到旧版。
5. 考试、成绩、学生档案、其他报告和已有查询授权应保留。
6. 点击「操作记录 → 查看报告明细」：能看到上传、替换、删除的报告ID、考试、类别、科目、对象、文件、版本、操作人、时间与原因；替换记录包含新旧文件。

## 列表快速检查

切换「全部报告／诊断报告／作文批改报告」，尝试按考试、类型、科目、年级、班级筛选，再搜索报告ID、对象或文件名。每页 12 份，支持跨页勾选；无匹配结果时显示空态，重置后可恢复列表。
