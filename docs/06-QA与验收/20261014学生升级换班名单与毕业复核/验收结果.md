# 学生升级／换班名单与毕业复核修复

日期：2026 年 10 月 14 日。

## 修复内容

1. 上传名单页的下载文件包含勾选学生的资料，五列表头为「学生ID、账号、姓名、目标年级、目标班级号」。目标年级、班级默认沿用原值，办理人按实际安排修改；未勾选时导出当前筛选范围内可办理的在读、毕业学生。重复ID、跨校学生、离校学生及已停用的在读账号会被拦截。
2. 下一学年流程顺序调整为：选择办理分支 → 上传名单 → 毕业办结与完整性审核 → 校验与身份审核 → 年级异常审批 → 预览并确认。当前学年普通调整继续跳过全校完整性检查；包含毕业生时先复核本批毕业记录。
3. 毕业审核只展示已办结毕业的学生，包含姓名、账号、学生ID、原毕业年级／班级、上传名单中的复读年级／班级。移除逐行毕业勾选和非毕业剔除依据，底部仅保留「我已逐人核对实际毕业名单」确认。
4. 已毕业学生可通过升级／换班办理同学段复读，须完成身份核验和返校安排审批。确认后恢复原账号与在读状态、撤销毕业归档，保留学生ID、原密码、历史成绩和考试时的班级归属。跨学段返校仍被拦截。
5. 毕业原班级从已完成毕业任务或毕业学年记录读取，避免同学年恢复在读后原毕业班级被新班级覆盖。未办结的应届毕业、全校在读名单遗漏仍会阻止学年切换。毕业清单发生变化后须重新确认。
6. 打开未结束的历史办理任务时重新读取当前校验结果，已完成任务保留原回执。

## 人工复测

刷新学生档案页面，勾选学生后打开「升级／换班」，进入上传名单页下载文件，核对只包含所选对象且五列已填入对应资料。按实际安排修改目标年级和班级，上传后核对第 3 步毕业清单中的原毕业班级与复读目标，确认底部核对选项，再进入第 4 步身份审核；完成需要的年级审批后确认生效。使用已毕业的同学段学生测试复读，回查学生ID、账号、历史成绩及考试班级归属。
