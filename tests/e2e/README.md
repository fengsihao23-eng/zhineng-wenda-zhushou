# 浏览器回归测试

从仓库根目录运行。Playwright 依赖和配置统一放在根目录，避免前端子目录与根目录加载不同版本的测试运行器。

```sh
npm ci
npx playwright install chromium
npm run test:e2e
```

默认访问生产入口 `http://localhost`，可用 `PLAYWRIGHT_BASE_URL` 指定另一个已有测试部署。性能用例明确要求生产构建；不要指向 Vite 开发服务器。

需要同时构建和启动本地服务时，运行 `./scripts/run-e2e-tests.sh`。该脚本保留现有数据；仅在独立测试环境中用 `E2E_SEED_DATA=1` 初始化示例账号和业务记录，并显式设置 `DEPLOY_APP_ENV=test`。初始化依次执行 `apps/api/scripts/init_test_data.py` 和 `apps/api/scripts/seed_platform.py`：前者创建学生、成绩和报告，后者创建教师、学校管理员、市级运营账号及教师的班级/科目授权。两步均可重复执行，生产环境禁止示例数据初始化。运行用例需要种子账号：张三 603 分、李四 664 分、各两次考试和五科成绩。

从 `apps/web` 也可运行 `npm run test:e2e`；它转发到同一个根目录运行器。先在根目录安装依赖。

```sh
npm run test:e2e -- --project=chromium tests/e2e/profile.spec.ts
npm run test:e2e:ui
npm run test:e2e:report
```

## 检查范围

当前 10 个文件、71 项用例，配置 Chromium：认证 7、聊天 8、诊断 9、错误处理 4、性能与稳定性 7、成绩概览 13、成绩查询 9、简单验证 3、冒烟 7、旧趋势可视化 4。

成绩概览检查真实分数、同文档账号切换、雷达轴填充、独立百分比轴的坐标、满分 null/0/负数、断网恢复、首页样式隔离、320/375/390/768px 内容宽度和折线可绘制区域。性能使用生产构建、禁用 HTTP 缓存，导航后实际成绩与图表可见均须低于 2000ms。

登录、会话管理、成绩和诊断列表访问真实 API。`utils/chat-stream.ts` 为聊天回复提供受控 SSE，验证流协议、来源呈现、停止、错误和重试；这些测试不证明真实模型回答质量或工具选择。权限和数据隔离还需结合后端回归测试。故障和边界用例拦截浏览器响应，不更改成绩数据。

诊断页区分未授权与授权后无报告：BASIC 账号须收到真实接口的 `403 / ENTITLEMENT_REQUIRED`，页面显示授权提示；已授权账号的空列表通过受控响应检查空状态。正式报告的说明在点击「报告说明」后验证。管理端错误处理先通过真实教师/管理员登录，教师恢复列表须遵守显式班级与科目授权。

结果位于根目录 `playwright-report/` 和 `test-results/`。CI 从根目录构建生产服务、等待健康检查、初始化独立测试数据并运行同一套命令，保存报告与原始结果。当前没有量化代码覆盖率或真实手机弱网通过率的声明。
