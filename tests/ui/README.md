# 页面与列表交互回归

在仓库根目录运行：

```bash
npm run test:ui
```

使用 Chromium、独立 Vite 服务（127.0.0.1:5187）和合成 API 响应，不需要启动后端或数据库。首次使用需要安装根目录与 `apps/web` 的 npm 依赖，以及 Playwright Chromium。

覆盖以下行为：

- 师生信息列表与导入、历史回执分开；批次页面可以直接刷新，保留返回入口。
- 成绩导入、试卷、报告和旧资料的上传表单从列表入口进入独立页面。
- 提示说明默认隐藏，可点击打开，通过关闭按钮、外部点击或 Escape 关闭。
- 服务端与本地列表的每页条数、总数、筛选重置、末页和空结果。
- 删除末页最后一条记录后自动返回有效页；只读角色保持只读。
- 学生复习与支持记录的独立入口，以及 390px 手机布局。

截图和失败记录保存在 `test-results/ui/`。实际 API 的分页、参数边界及学校隔离由 `apps/api/tests/test_education_workbench.py` 验证；真实导入流程使用 `tests/education/` 的浏览器验收。
